# Tauri 实验版中文说明

这是独立 Windows 桌面外壳验证版，**不是新正式版，也不是 Rust 全量重写**。以 v1.8.9 为基线保留原有页面和 Node 后端，使用 Tauri 与系统 WebView2 显示界面，另外补入 v1.8.10 的 Electron 退出修复及守门测试。Tauri 包本身不运行 Electron。

普通用户继续使用 [正式版](https://github.com/Northfish0311/DJI-4G-Assistant/releases/latest)。本实验不发布 Release，不覆盖正式版，暂时不要替换日常使用的软件。

## 下载和打开

1. 登录 GitHub，打开 [实验构建列表](https://github.com/Northfish0311/DJI-4G-Assistant/actions/workflows/tauri-lab.yml?query=branch%3Aexperiment%2Ftauri-win-shell)，选择最新成功的 **Tauri Windows lab**。
2. 在页面下方 **Artifacts（构建附件）** 中下载 **DJI-4G-Tauri-Lab** 并解压。不是下载 Source code，也不是去 Releases 找实验包。
3. **推荐先试免安装版：** 再解压其中的 `portable.zip`，双击 `dji-4g-tauri-lab.exe`。不要在压缩包中运行，不要单独移动 exe；旁边的 `payload` 文件夹必须保留。
4. 想安装时，选择 `nsis` 文件夹中的 `DJI 4G Tauri Lab_0.1.0_x64-setup.exe`。安装版和免安装版选一个即可。
5. 先退出正式版助手，再打开实验版，避免争用串口。窗口名为 **DJI 4G Tauri Lab**，数据目录和配对密码与正式版分开。

程序自动启动服务并打开界面，**不用另装 Node.js，不用运行黑色命令窗口，不用手动输入网址**。未连接模块时只能检查界面，不能验证读卡或短信。

需要 Windows x64 和 WebView2。安装器可下载 WebView2 引导程序，这部分额外下载不计入安装包大小。包内提供 Node、USB 原生依赖、lpac 和 C# 短信读取器，但不会自动修复 Windows 串口驱动，遇到能上网却无法管理时看 [驱动说明](../../docs/Windows驱动说明.md)。

实验包可能出现未知发布者提示。请核对仓库、提交和附件校验值；来源不明时不要运行，不要关闭系统安全防护。构建附件保留 14 天，到期后选择新成功构建；维护者可手动运行工作流生成新包，无需发布 Release。

## 功能范围

| 功能 | 实验状态 |
| --- | --- |
| 窗口与页面 | 已在本机打开并截图检查，修复 API 版本常量作用域错误 |
| 设备、网络、短信收件箱、eSIM 枚举 | 保留读取入口，本轮未连接模块，不代表实机验证完成 |
| 发删短信、eSIM 启停及下载等写入 | 关闭 |
| 拨号、接听、挂断、USB 模式修改、重启、原始模块改造 | 关闭 |
| Electron 网卡提权、麦克风授权和音频桥 | 尚未移植，不承诺声音功能 |
| 手机和平板远程管理 | 默认仅本机；可选局域网测试尚未完成配对实测 |

启动时会清除所有 `ALLOW_*` 写入授权，不能通过设置环境变量解锁完整功能。**页面中有按钮，不代表实验版已开放该操作。** 不要为试用改动模块 VID/PID、usbnet 或套餐。

## 实测结果与限制

2026-11-19 首轮验证对应提交 `a5f50dd`、[构建 44478817929](https://github.com/Northfish0311/DJI-4G-Assistant/actions/runs/44478817929)：

- 自动化测试 334 项通过，0 项失败。
- 自带后端的认证、静态资源、禁写和父进程管道断开退出检查通过。
- 打包后的真实 exe 在云端与本机通过启动、健康检查及 Job Object 退出清理测试。
- 实际打开窗口并截图，修复后自动扫描不再出现 `CONSOLE_API_VERSION is not defined`。
- 安装包 28,688,843 字节（约 28.7 MB）；免安装 ZIP 46,940,422 字节（约 46.9 MB）。这是 USB 多平台裁剪之前的数据，新包以构建日志为准。
- 无模块扫描结束后的单次快照约 317 MiB 私有内存、12 个进程，包括 WebView2、Node、PowerShell 和控制台宿主。

这不是统一条件下与 Electron 的性能对比，不能承诺两个进程、内存减半或 10 MB 安装包。压缩包大小、解压后大小和运行内存不是同一个指标。

启动和点击「自动扫描」都只做基本识别。不必先读完短信或枚举 eSIM 才能看概览；打开相应页面时才读取详情。没有找到 AT 串口时不再猜测 COM5，也不会继续读短信、套餐或模块状态。若 Windows 能确认模块 USB 设备存在但 AT 口未响应，先检查串口驱动或关闭其他占用模块的软件，不要更改套餐。系统无法提供 USB 详情时只提示等待连接。

尚未完成：真实模块短信、多 EID、串口释放、手机配对、通话、冷启动及标准化资源对比。

## 退出保护和体积优化

启动扫描复用「查找 AT 口」时实际枚举的端口列表，不再为概览先单独查一次。连接后仍会检查端口变化；遇到没有返回列表的旧后端，会回退到独立查询。此优化减少一次请求，不会消除首次启动 PowerShell 的成本。

源码保留 Electron 外壳用于对照，所以同步保留 v1.8.10 退出修复及关窗守门测试；旧基线不是丢失修复的理由。Tauri 另有真实 exe 生命周期测试，验证 Job Object 关闭后后端监听释放，两套保护不能互相替代。

Windows x64 实验包仅保留 `usb/prebuilds/win32-x64`。裁剪只发生在生成的打包目录，不删除源项目依赖或许可证。缺少目标平台文件时构建失败；裁剪后仍验证 USB 原生库可加载。

Node SEA 把脚本和资源装入 Node 可执行文件，**不等于自动裁掉 Node 运行时**。当前没有实施 SEA 或 Rust 后端重写，不承诺 SEA 一定显著缩小体积。后续先测量完整包，再决定是否迁移串口等热点路径。参见 [Node SEA 官方说明](https://nodejs.org/api/single-executable-applications.html)。

## 可选的手机和平板测试

默认只允许 Windows 本机访问。需要测试局域网时，先退出实验版，在免安装目录打开 PowerShell 运行：

```powershell
.\dji-4g-tauri-lab.exe --lan
```

手机与电脑连接同一可信局域网，模块仍插在 Windows 上，电脑保持运行。使用实验版当次显示的地址和自己的配对信息，不复用正式版地址或密码。端口自动分配，不固定为 8787；手机的 `127.0.0.1` 指手机自己，不是电脑。

局域网配对尚未实测，不是手机直插模块的独立版。不要进行公网端口映射或使用无认证隧道。
