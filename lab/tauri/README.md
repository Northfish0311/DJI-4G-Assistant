# Tauri 验证版（非正式发布）

基于 Windows v1.8.9，复用该版本页面和 Node 后端。这不是最新版正式版，也不是 Rust 全量重写。

## 如何试用

1. 在本实验分支 Actions 中打开成功的 Tauri Windows lab 构建，下载 DJI-4G-Tauri-Lab 附件。需要登录 GitHub，不是 Releases。
2. 解压附件。nsis 文件夹中是安装版；portable.zip 解压后运行 dji-4g-tauri-lab.exe，不要单独移动 exe。
3. 实机测试前先退出正式版助手，避免两个后端争用串口。实验版有独立名称和数据目录，不覆盖正式版或旧配对密码。
4. 默认仅本机使用。手机测试需退出实验版，再以 --lan 参数启动，在同一可信局域网使用实验版自己的密码和动态端口。

需要系统 WebView2。安装器可下载 WebView2 引导程序，这部分网络下载不计入安装包大小。包内提供 Node、USB 原生依赖、lpac 和 C# 读取器，无需用户另装 Node。

## 当前范围

- 保留设备和网络读取、短信收件箱、eSIM 枚举页面。
- 关闭所有 ALLOW_* 写入权限，不能发删短信、切换/下载套餐、拨号或重启模块。
- 未移植 Electron 的网卡提权按钮、麦克风授权和音频桥，不承诺音频功能。
- 不向远程网页开放 Tauri 系统命令调用入口。
- 关闭壳或壳崩溃后，Windows Job Object 终止这个实例的 Node 及其派生进程；Node 也监测父进程管道断开。

## 验证边界

CI 测试独立后端的认证、静态资源、禁写和退出，不读取模块。编译 Rust 和打包后还用真实 exe 启动后端，并验证 Job Object 关闭后监听端口释放。成功编译不等于界面或实机通过。

仍需分别验证：空短信列表、多 EID、退出释放串口、手机配对、首次可操作时间、整个进程组空闲内存。暂不宣称 10 MB、两个进程或内存减半。
