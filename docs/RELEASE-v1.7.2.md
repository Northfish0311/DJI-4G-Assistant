# DJI 4G Assistant v1.7.2

本次更新修复联网状态误判、Windows 实时流量统计，以及 AT 工具菜单的顶部直角问题。

## 怎么下载和更新

1. 普通用户下载 **DJI-4G-Assistant-Setup-1.7.2-x64.exe**。
2. 关闭正在运行的旧版 DJI 4G Assistant，再双击新安装包完成更新。
3. 打开桌面上的 DJI 4G Assistant，程序会自动识别模块。

不想安装时，可以下载 **DJI-4G-Assistant-Portable-1.7.2-x64.exe** 直接运行。两个文件功能相同，选一个即可，不需要另外安装 Node.js。

`SHA256SUMS.txt` 用于核对文件完整性；`Source code` 是开发者源码，不是安装包。程序尚未购买商业代码签名证书，Edge 或 Windows 可能显示“未常见下载”或“未知发布者”。请核对下载来源为本仓库及文件校验值，不要关闭系统安全防护；如提示明确的恶意软件检测，应先停止安装并核查。

## 修复内容

- **联网状态更准确：** 全零 IP、未注册和注册被拒绝不再显示“已联网”。USB 网卡已连接与蜂窝网络注册分开判断，首页会定时刷新；读取失败时明确提示状态待确认。
- **实时流量恢复：** 针对 ECM 驱动返回异常计数的情况，优先使用名称精确且唯一匹配的 Windows 性能计数，不把电脑 Wi-Fi 的计数混入模块流量。无法确定来源或计数无效时显示原因。
- **速度和累计值更稳：** 首次读取显示“正在采样速度”，取得连续采样后才显示速度；计数重置、网卡或统计来源变化后重新计数，避免异常跳涨。
- **AT 菜单外观一致：** 选中 AT 工具时四角保持统一圆角，分隔线与按钮分开，不再出现顶部被削平的效果。
- **中文说明同步：** 补充流量统计范围，以及 USB 网卡连接不等于蜂窝互联网可用的说明。

## 流量统计的范围

“当前下载/上传”是当前 USB 网卡连续采样计算的平均速度，包含电脑与模块本地网关之间的通信；不是套餐剩余流量。“本次下载/上传”从当前页面首次有效采样开始，重新打开页面或计数重置时重新累计。模块直插手机或平板期间的流量不在 Windows 统计范围内。

## 验证范围

- 84 项自动测试和 JavaScript 语法检查通过。
- 在真实 Quectel ECM 网卡上核对了独立于 Wi-Fi 的计数，并验证本地网关通信期间上传、下载计数增长；这不是蜂窝互联网测速。
- 使用模拟设备数据检查了 1440、1024、390 像素三种布局，AT 菜单圆角一致，页面没有横向溢出。
- 本次验证没有发送短信、拨打电话、切换套餐、修改模块配置或删除短信。

本次是 Windows 修复更新，不新增 Android 或 iOS 直插管理能力。
