# 大疆 4G 助手 v1.7.17

## 下载与安装

普通用户下载 **DJI-4G-Assistant-Setup-1.7.17-x64.exe**。先退出旧版，再双击安装；安装后从桌面图标打开，不需要另外运行启动脚本。

- `Portable`：免安装版，与安装版功能相同，二选一即可。
- `SHA256SUMS.txt`：校验文件，不需要打开运行。
- `Source code`：开发源码，不是安装包，普通用户不用下载。

软件尚未购买商业代码签名，Edge 或 Windows 可能显示发布者/信誉提醒。请核对来源为本仓库，不要关闭系统安全防护。

## 本次修复

- 修复 v1.7.16 中语言文件拆分后测试仍按旧文件结构加载的问题，恢复日志、短信、流量、配对和中英文界面的原有检查，未删除安全断言。
- 通话中 `CLCC` 暂时为空、`CPAS` 缺失或出错时，不再直接判定通话结束。保留已有声音连接和上一条已知通话信息，界面明确显示“正在确认”。
- 等待确认时保留“挂断”入口，暂停自动按键发送和短信/eSIM 后台查询；恢复有效通话状态后继续正常显示，不重复开启麦克风。
- 后台关闭声音前，在声音操作队列内再次读取 `CLCC` 和 `CPAS`。仅在通话列表有效且没有活动语音通话、`CPAS=0` 时自动关闭，避免排队期间新来电话被误清理。
- 将独立语言文件纳入语法检查和安装包静态资源检查，新增中英文键名、加载顺序及通话边界测试。
- 同步版本号、依赖锁文件与中文下载说明。

## 验证与限制

自动化检查包含原有回归测试、模拟通话状态异常、浏览器中英文切换及安装包启动检查。模拟测试不会拨号、发短信、切换 eSIM 或修改模块配置。

**本轮未进行真实通话。** 这些修复防止软件把暂时读不到状态误判为结束，不等于运营商 IMS、语音套餐、模块固件或声音接口问题全部解决。电话声音仍属实验功能。

不支持 CPAS 的设备在没有已知通话或声音连接时仍可正常进入空闲状态；已有通话的状态无法确认时会保留连接，可手动挂断或停止声音，不会因超时擅自拆除。
