# 大疆 4G 助手 v1.7.16

## 下载与安装

普通用户下载 `DJI-4G-Assistant-Setup-1.7.16-x64.exe`，先退出旧版，再双击安装即可。
`Portable` 是免安装版；`SHA256SUMS.txt` 用于校验；`Source code` 是开发源码，不需要一起下载。

软件尚未购买商业代码签名，Edge 或 Windows 可能显示发布者/信誉提醒。请核对来源为本仓库，不要关闭系统安全防护。

## 这次改了什么

- **修复电话被误挂断：** 通话中串口短暂丢失响应时，程序只凭一次 `AT+CLCC` 返回空就判定通话结束，导致正在进行的电话被自动挂断。现在改为同时用 `AT+CPAS` 确认模块真实通话状态——只有 CPAS 也确认不在通话中，才会断开语音路由和音频桥。通话稳定性明显改善。

## 验证范围

- 电话通话状态轮询、语音路由拆除逻辑新增 CPAS 双重确认，已通过语法与启动冒烟校验。
- 界面文案整理为独立语言文件，中英文切换与显示不变。

本轮未进行真实通话、未发短信、未删除短信、未切换 eSIM、未修改 USB 模式。电话声音仍属实验功能，流量统计不是套餐剩余量。
