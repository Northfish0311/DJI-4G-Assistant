# 大疆 4G 助手 1.8.8 · Windows 64 位

先退出旧版。两个文件选一个即可，不需要安装 Node.js：
- [安装版（推荐）](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/v1.8.8/DJI-4G-Assistant-Setup-1.8.8-x64.exe)：双击安装，之后从开始菜单打开。
- [免安装版](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/v1.8.8/DJI-4G-Assistant-Portable-1.8.8-x64.exe)：双击直接运行。

## 这次改了什么

- **网络优先级操作不再可能卡死**：以前点「优先使用 Wi-Fi」或「恢复原优先级」时，如果 Windows 的网络接口查询卡住，按钮会一直显示忙碌，只能重启程序。现在这类调用最多等 20 秒，超时会明确报错并恢复按钮。
- **版本对不上时会直接说**：电脑端升级后，手机或浏览器可能还开着旧页面，表现是某个按钮点了没反应。现在页面会比对电脑端的接口版本，不一致时提示先强制刷新；刷新后仍然提示，就说明两边的程序版本需要对齐。
- 没有其他功能变化。1.8.7 的「优先走 Wi-Fi」、短信长会话与清理、eSIM 卡号遮蔽、通话声音活动显示都保持不变。

## 验证边界

本次改动只涉及网络优先级调用的等待上限与版本提示，已在 Windows 上通过完整回归（331 项）验证；**模块实机组合验证（电脑实际走 Wi-Fi 且收到新短信）仍未完成**，结论同 1.8.7。

Edge 或 Windows 可能提示文件不常见。请只从本仓库下载，无需关闭安全防护；可用同一发布页的 `SHA256SUMS.txt` 对照下载文件的 SHA256。
