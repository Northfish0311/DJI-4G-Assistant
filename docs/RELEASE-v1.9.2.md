# 大疆 4G 助手 1.9.2 · Windows 64 位

先退出旧版。[安装版（推荐）](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/v1.9.2/DJI-4G-Assistant-Setup-1.9.2-x64.exe) 与[免安装版](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/v1.9.2/DJI-4G-Assistant-Portable-1.9.2-x64.exe) 二选一。下载后双击，不需要另装驱动以外的运行环境。

**网络 → 禁止大疆流量**：先连 Wi-Fi 并插入模块。确认后，Windows 停用这张大疆 USB 网卡；即使 Wi-Fi 掉线，电脑也不会通过它上网。模块的 USB 网页同时不可用；不改 AT 短信串口、SIM、APN 或 Wi-Fi。**允许大疆流量** 可重新启用这张网卡。只想调整优先顺序，请使用原来的“优先使用 Wi-Fi”。

仅支持唯一匹配的 Quectel ECM 网卡，不会猜测未知设备。更换 USB 插口或模块可能产生新设备实例，需重新设置。此功能不限制其他网卡或 VPN，也不诊断所有“等待网络”的原因。手机浏览器无法修改电脑网卡。
