# DJI 4G Assistant v1.7.8

## 下载与安装

普通用户下载 **DJI-4G-Assistant-Setup-1.7.8-x64.exe**，退出旧软件后安装，再打开桌面图标。Portable 是免安装版；SHA256SUMS 用于校验；Source code 是开发源码，不是安装包。

## 本次补充修复

- 本机拨打或接听前准备已下载并校验的临时声音驱动，不改 USB、IMS、APN、eSIM 或运营商配置。
- 由 Windows 本页拨打或接听的电话进入接通状态后，自动连接所选耳机/扬声器和麦克风，不再漏掉“启动声音”步骤。自动连接失败明确显示错误，原按钮仍可重试。
- 通话期间更及时读取状态，不堆叠串口请求。中断、换卡或挂断时取消过期声音准备，释放麦克风和自有声音路由。
- 通话结束后自动只读查询模块结束码和 IMS/LTE 状态；过期查询不会覆盖下一通电话。不把统一的 `NO CARRIER` 归咎于 SIM。
- 包含 v1.7.7 的语音文件下载进度与错误、Windows AC Interface 声卡识别、临时驱动准备、IMS 备份与恢复、实体 SIM 提示修复。

## 使用耳机

1. 完成“电话 → 通话设置”的一次性设置。
2. 选耳机对应的“扬声器”，选择有麦克风的输入设备；普通无麦耳机仍需要电脑麦克风。
3. 把系统音量调低，再拨打或接听。接通后自动连接声音；失败时看提示并用“启动声音”重试。

不会改变系统音量，也不会把耳机听到的声音回送给模块造成环路。远程手机/平板不承载 Windows USB 通话声音。
