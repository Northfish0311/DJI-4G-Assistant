# 安卓远程助手 0.1.0（测试版）

**下载 `DJI-4G-Remote-Android-0.1.0-test.apk`，传到安卓手机后打开安装。最低 Android 7.0。**

模块仍插在 Windows 电脑上。保持电脑助手运行，两台设备连接同一可信局域网，在安卓 App 中扫描电脑“连接手机 / 平板”页面里的配对二维码。

支持扫码/手动配对、加密保存配对信息、远程管理页面、操作确认与输入弹窗、手动重连和忘记电脑。不支持模块直插安卓，不提供手机端通话音频，不需要 Apple 开发者账号或 TestFlight。

本次直接使用构建 35221564045 的 APK，不重新编译或重新签名。编译、单元测试、静态检查和模拟器启动截图已通过；真实手机、真实扫码及模块操作还需测试。

此为调试签名测试包，不是商店正式版。其他构建的调试证书可能不同；出现签名冲突时需卸载旧测试包再安装并重新配对。不要关闭系统安全扫描，只在确认下载来源后允许本次来源安装应用。

`SHA256SUMS.txt` 用于校验；PNG 是模拟器截图；Source code 是源码，都不是要安装的软件。不修改现有 Windows 1.6.2 或 iOS 发布。
