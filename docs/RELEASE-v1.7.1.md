# DJI 4G Assistant v1.7.1

本次更新修复 Windows 实机测试中发现的网卡状态与桌面配对细节，并补全中文界面说明。

## 下载

普通用户下载 **Setup** 安装版；需要免安装运行时下载 **Portable**。两者功能相同，包含运行所需依赖。可使用同页的 `SHA256SUMS.txt` 核对文件。

## 更新内容

- Windows 网络页不再重复堆积较慢的网卡查询，多台浏览器同时打开时也会共用同一次检测。
- 加快 Quectel ECM 接口、IPv4 和网关识别；过滤部分 ECM 驱动返回的无效流量计数，避免显示错误的超大数值。
- 修复驱动已出现但网卡尚未创建时的兜底状态，第一次插入设备时提示更准确。
- 桌面程序等待配对二维码、局域网地址和复制按钮全部就绪后再判定配对成功。
- 隐藏式桌面烟雾测试不再依赖 GPU，可在本地和自动构建环境中稳定核对打包程序。
- 补全系统页中文说明，中文界面不再夹杂英文段落。

## 实机验证

- 使用 Baiwang/QDC507 模块验证了 AT 口自动发现、模块状态、短信收件箱、双 EID 与 Profile 列表、电话能力、Windows ECM 网卡、IPv4、网关、驱动信息和局域网配对二维码。
- 实机读取到 2 个 EID 空间与 3 个 Profile；短信仓库可读取 21 条短信。
- 项目测试、JavaScript 语法检查、桌面窗口烟雾测试和 Windows 安装包构建均通过。
- 测试未发送短信、未拨打电话、未切换 eSIM Profile，也未修改 USB 模式，避免产生资费或改变设备状态。

实际 Profile、短信送达、语音声音和网络能力仍取决于模块、卡片、Windows 驱动及运营商。危险写入继续需要明确确认，未知设备不会自动套用配置。
