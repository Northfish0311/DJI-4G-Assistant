# 大疆 4G 助手 1.8.9 · Windows 64 位

先退出旧版。两个文件选一个即可，不需要安装 Node.js：
- [安装版（推荐）](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/v1.8.9/DJI-4G-Assistant-Setup-1.8.9-x64.exe)：双击安装，之后从开始菜单打开。
- [免安装版](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/v1.8.9/DJI-4G-Assistant-Portable-1.8.9-x64.exe)：双击直接运行。

## 这次修了什么

- **删不掉最旧的那条短信**：部分模块的短信索引从 0 开始编号，而程序按 1 起算，于是索引 0 的短信被判为非法——单条删除会报错，批量清理跑完也仍然留着它，看起来像“删了但数量没变”。现在 0 和 1 起的模块都能正常删除。
- 其余功能与 1.8.8 相同：Wi-Fi 优先级调用有 20 秒上限、页面与电脑端版本不一致时会提示、1.8.7 的「优先走 Wi-Fi」与短信长会话/清理等保持不变。

## 验证边界

索引问题在本机联通模块（索引 0–5）上实测复现并验证修复；单元测试 332 项通过。**模块实机组合验证（电脑实际走 Wi-Fi 且收到新短信）仍未完成**，结论同 1.8.7、1.8.8。
