# DJI 4G Assistant（大疆 4G 助手）中文使用说明

DJI 4G Assistant（大疆 4G 助手）包含 Windows 主机程序和原生 iPhone/iPad 客户端，把模块诊断、网络状态、eSIM、短信、电话、USSD、AT 工具和原始模块初始化放在同一个界面里。

## 第一次使用

1. 打开 [GitHub Releases](https://github.com/Northfish0311/DJI-4G-Assistant/releases)，找到最上方带 **Latest** 标记的版本。
2. 下载 `DJI-4G-Assistant-Setup-版本号-x64.exe`。普通用户只需要这个文件。
3. 双击安装包，按提示完成安装。
4. 把 SIM/eSIM 卡装进模块，再把模块插入 Windows 电脑。
5. 双击桌面上的 **DJI 4G Assistant** 图标。
6. 等待程序自动发现 AT 口并读取设备状态。只有需要重新检查时才点击右上角“自动扫描”。

正常情况下不用查 COM 号、不用手工填写 `COM5`，也不用先打开黑色命令窗口。安装版和便携版双击后都会直接打开管理界面。

安装版会创建桌面和开始菜单快捷方式。项目目前没有购买商业代码签名证书，因此 Edge 下载和 Windows 首次安装时可能显示安全提醒。

### Edge 下载时提示不安全怎么办

1. 先确认浏览器地址是 `github.com/Northfish0311/DJI-4G-Assistant`，下载文件名以 `DJI-4G-Assistant-Setup-` 开头并以 `-x64.exe` 结尾。
2. Edge 显示“此文件不常下载”或类似提示时，打开该下载项右侧菜单，选择“保留”。
3. 如果 Edge 再次询问，选择“显示详细信息”或“仍然保留”。
4. 不要关闭 Edge 的整体安全功能，也不要从网盘、聊天附件或陌生镜像下载本软件。

### 安装时 Windows 再次提醒怎么办

1. 双击安装包后，如果出现“Windows 已保护你的电脑”，先确认文件名仍然正确。
2. 点击“更多信息”。
3. 点击“仍要运行”，然后按安装向导继续。
4. 如果下载地址不是本仓库、文件名异常，或 SHA256 与 `SHA256SUMS.txt` 不一致，请停止安装并删除文件。

这是未购买商业代码签名证书造成的信誉提醒，不代表可以忽略所有安全警告。只对本仓库 Releases 中、校验一致的安装包执行以上步骤。

## 六个常用操作

### 1. 检查模块能不能上网

1. 插好 SIM/eSIM 和模块，打开软件。
2. 等待软件自动读取核心状态；需要完整复查时再点击右上角“自动扫描”，等待检查结束。
3. 在“概览”确认 SIM 为 `READY`、网络为“本地注册”或“漫游注册”，并显示运营商、信号和模块 IP。
4. 打开“网络”，确认 Quectel ECM 网卡已连接，并获得 IPv4、网关和 DHCP。

蜂窝已经注册但 Windows 网卡未连接时，只检查“网络”页和驱动，不要重新写 eSIM、VID/PID 或 APN。

### 2. 读取和发送短信

1. 打开“短信”页。
2. 点击“刷新”读取模块存储中的短信；验证码会单独显示并可复制。
3. 如果页面提示短信容量已满，例如 `23/23`，先确认并删除一条不需要的旧短信，否则新短信可能无法写入。
4. 发短信时填写收件号码和正文，点击“发送短信”。
5. 核对号码并确认。软件显示“模块已接受”后，是否最终送达仍由运营商和套餐决定。


### 3. 切换已有 eSIM 套餐

1. 打开“eSIM”页，点击“刷新全部 EID”。
2. 在“EID 卡库”中选择目标空间；如果只有一个，程序会自动选中。
3. 可点击“备注”写入本地名称，例如“长期卡”或“测试卡”，方便以后区分。
4. 在所选 EID 的套餐列表中找到目标套餐，点击“切换到此套餐”。
5. 确认后不要拔卡、拔模块或关闭软件。
6. 等待 30–60 秒，软件会重新读取状态；如页面没有及时更新，再点击“自动扫描”确认新运营商已经注册。

当前套餐会标记为“正在使用”。切换、停用、改昵称、通知处理和删除都绑定当前 EID；切换 EID 后，上一空间的待下载结果和通知会立即清空，避免混淆。
### 4. 下载新的 eSIM 套餐

1. 向套餐商取得你自己购买套餐的完整 `LPA:1$...` 激活码。
2. 打开“eSIM”，先在“EID 卡库”选择要写入的目标 EID。
3. 展开“下载新套餐”，粘贴完整激活码。
4. 点击“下载”；确认框会再次显示目标 EID 的备注和尾号，核对后确认。
5. 完成后刷新列表，再选择是否启用新套餐。

下载只会向当前所选 EID 新增 Profile，不会自动删除已有套餐。激活码不会保存到项目或浏览器本地存储。下载中不要切换 EID、拔卡、拔模块或关闭程序。
### 5. 初始化刚买来的原始模块

程序启动后会先自动扫描。只有程序确认设备属于已验证的 Baiwang/QDC507 风格原始模块，并读取到真实配置时，才使用“原始模块设置”。

1. 先点“检查原始 USB”，只读核对 VID/PID、型号、固件和 `usbcfg`。
2. 按页面要求输入确认词，完成 VID/PID 转换。
3. 等模块重新出现后，再单独确认 `usbnet=1`。
4. 重新插拔并自动扫描，确认 COM 口和 ECM 网卡都出现。

如果模块已经是 `2C7C:0125 + usbnet=1` 且能联网，不要执行初始化。

### 6. 接打电话和准备声音

电话控制和电话声音是两件事：

- 拨号、接听、挂断、来电号码和 DTMF 使用 AT 指令，支持语音的 SIM/eSIM 注册后即可测试。
- 双向声音还需要模块向 Windows 提供 USB 音频，并在 QDC507 内部建立 VoLTE 音频路由。

先测试电话控制：

1. 打开“电话”页，输入真实号码后点击“拨打”；来电时点击“接听”。
2. 页面显示“正在拨号”“通话中”或来电号码，说明 AT 呼叫控制已经工作。
3. 能建立呼叫不代表声音已经配置。

第一次准备 QDC507 声音：

1. 点击“下载运行时”。程序从固定 MaVo commit 下载 6 个文件到本机，并核对固定大小和 SHA-256。此步不改模块。
2. 点击“打开 ADB 和声音”，阅读确认框后确认。程序只支持精确识别的 `QDC507 / QDC507GLEFM21`，会保存同一模块的本地 USB 备份，保留 VID/PID 和前五个现有 USB 功能，只把 ADB、UAC 两位打开，然后重启模块。
3. 等模块重新出现。如果显示“需要 ADB 驱动”，打开 [Zadig 官网](https://zadig.akeo.ie/)，在“Options”中显示全部设备，只选择 `QDC507 ADB MI_06` 或页面检测到的 `ff/42/01` ADB 子接口，目标驱动选择 WinUSB。
4. 绝对不要在 Zadig 中替换 Quectel 复合设备本体、ECM、AT、NMEA、Modem 或 USB Audio。选错会让上网、串口或声音消失。
5. 可以点击“准备通话声音”提前检查；这一步只把匹配内核模块临时加载到模块内存。也可以不提前点，通话接通后第一次点击“启动声音”时会自动准备。
6. Windows 第一次询问麦克风权限时允许。挂断后程序会停止自有声音路由并释放麦克风。

以后日常使用：

1. 插模块并打开软件。
2. 拨号或接听。
3. 接通后点击“启动声音”。模块重启后的临时准备会自动完成，不需要再次修改 USB 配置。
4. 挂断即可。

“恢复最近 USB 备份”只对备份中的同一 IMEI 和 VID/PID 开放。它恢复写入前的七位 `usbcfg` 并重启模块，但不能保证撤销已经持久授权的 QADBKEY。启用 ADB/UAC 的设计会保留 ECM 网卡位，但复合设备接口发生变化后，iPad/iPhone 的识别仍需实机验证；需要回到原接口时使用恢复按钮。

该声音路线属于精确固件限定的实验功能。它不会写 boot、MTD、DIAG 或 EDL，运行时内核模块在重启后消失。运营商语音/VoLTE、模块 DSP、Windows 声卡和麦克风权限任一不满足时，仍可能出现能拨号但没有双向声音。


## 页面功能

### 总览
显示 USB 身份、AT 端口、SIM、运营商、信号、注册状态、无线制式、APN、PDP 和模块 IP。程序启动时自动读取核心状态，“自动扫描”只读取信息并重新检查，不会修改模块。

### 网络
显示 Windows 网络适配器、连接状态、IPv4、网关、DHCP、驱动版本和本次运行的收发量。少数 ECM 驱动不提供可信流量计数，软件会显示 `--`，不会把异常计数当成真实流量。

“安装或修复官方驱动”只针对精确识别为 `USB\VID_2C7C&PID_0125&MI_04` 的 Windows ECM 接口。点击后输入 `ECMDRIVER`，再通过 Windows 管理员授权。程序从 Quectel 官方地址临时下载驱动，校验固定 SHA256、硬件 ID、版本、DHCP 配置和数字签名，备份当前 Quectel 驱动后再安装。仓库和 EXE 不内置驱动文件。

驱动已就绪时不会重复修改。目标接口不存在、下载内容变化、签名无效或管理员授权取消时会停止。这个操作只修复 Windows 驱动，不会修改模块的 AT、APN、SIM、eSIM Profile、VID/PID 或 `usbnet`。

切换 USB 网卡模式会写入并重启模块，只能用于已验证设备；已经正常联网的模块不要切换。

### eSIM
程序通过 lpac 读取 eUICC 标准 Profile，并用动态 EID 卡库管理多个独立空间。数量没有写死：一张卡能通过当前模块接口暴露 1 个、2 个、3 个或更多 EID，页面就显示对应数量。

自动识别流程：

- 检查标准 ISD-R AID、公开兼容 AID，以及本机以前只读验证成功的私有 AID。
- 对每个入口读取 `chip info`，只有返回合法 EID 才加入卡库。
- 按完整 EID 去重；同一 EID 从两个入口读到时只显示一次。
- 为每个 EID 单独读取 Profile、启用状态、剩余空间和通知。
- 先选择 EID，再执行启用、停用、改昵称、下载或删除，所有请求都带目标 AID。

每个 EID 可设置本地备注，如“长期卡”“备用卡”。备注和已验证的私有 AID 保存在本机 `.local` 目录，不写入卡片，也不会进入 Git 仓库。

如果卡商明确提供私有 ISD-R AID，可在“高级：添加私有 eUICC 入口”中输入。软件只接受合法十六进制 AID，并先执行只读 `chip info` 验证；验证失败不会保存。不要把 ICCID、激活码或随意猜出的字符串填在这里。

多 SE 卡也可能用厂商私有命令在不同安全空间之间切换。若模块当前只暴露其中一个空间，公开标准接口就只能读到一个 EID。程序不会尝试含义不明的 `SET/RUN` 指令，因为它们可能改变卡状态；这种情况需要卡商公开 AID 或提供有文档的切换协议后才能接入。

页面中的三个概念不要混淆：

- **EID 卡库**：当前接口实际验证成功的 eUICC 空间。
- **卡内套餐**：当前选中 EID 中已写入、且标准接口可读取的已启用和已停用 Profile。
- **待下载套餐**：GSMA SM-DS 中等待当前 EID 领取的 Profile，需要点击“检查待下载”。

套餐商 App 的订单数不等于卡内 Profile 数，bootstrap 身份也不一定作为普通 Profile 暴露。eUICC 通常不保存套餐剩余流量；界面中的流量是 Windows 网卡实际收发量，不是套餐余额，准确余额需要套餐商官方 API。
### 短信

收件箱按消息卡片显示号码、时间和正文，并识别常见 4–8 位验证码。发送使用 UCS2/PDU，支持中文和长短信分段。发送成功只代表模块接受请求，不代表对方已收到；漫游、短信中心、套餐权限和运营商风控均会影响送达。

页面会同时读取 `CPMS` 容量。接近满仓时会提示，达到例如 `23/23` 时会显示红色警告，因为模块可能无法再写入新短信。每条短信底部都有“删除”，确认后只删除当前索引，再自动刷新列表；没有提供“一键清空”，避免误删验证码和重要通知。

如果手机发送的新短信一直不出现，先看容量警告并删除一条不需要的旧短信，再重新发送测试。删除短信不可恢复，只在确认内容不再需要时执行。


### 电话

可监控来电、拨号、接听、挂断、读取来电号码并发送 DTMF。电话控制使用标准 AT 指令，并与现有数据连接分开识别，模块的 LTE 数据会话不会被误判为语音通话。

“电话”页会自动读取呼叫能力、当前七位 USB 组合、Windows ADB/UAC 接口和本地运行时状态。对于精确匹配的 `QDC507GLEFM21`，页面提供一次性声音向导：固定版本下载、USB 基线备份、只开启 ADB/UAC、WinUSB 驱动提示和临时语音路由。任何持久 USB 写入都必须确认，不会在自动扫描时执行。

第一次设置完成后，通话接通再点“启动声音”即可；模块重启后的临时驱动准备会由这一步自动执行。音频桥把模块下行送到 Windows 默认扬声器，把 Windows 默认麦克风送回模块 UAC。局域网手机和平板只能操作拨号和接听，不能代替插着模块的 Windows 电脑承载 USB 音频。

固件虽然可能返回 `AT+QPCMV=?`，但已验证的 `QDC507GLEFM21` 会拒绝实际 QPCMV 写入，因此本项目不会再使用那个无效声音路径。声音仍取决于 SIM/套餐、运营商 VoLTE、模块 DSP 和 Windows 音频权限，不能把“呼叫已接通”当成“双向声音已验证”。


### USSD
可发送运营商服务代码。并非所有漫游卡、数据卡或网络支持 USSD。

### AT 工具
用于读取模块和排错。危险写入默认拦截，不要执行来源不明的 `QCFG`、`CFUN`、`CGDCONT` 等命令。

### 系统
显示自动发现的 AT 端口和局域网地址。Windows 桌面版为当前用户持久保存随机控制密码，供 iPhone/iPad 配对一次后继续使用；源码启动器仍为每次运行生成临时密码。程序自动从 `8787` 开始寻找空闲网页端口；AT 端口输入框保持“自动”即可，不需要固定写成 `COM5`。

## 用 iPhone/iPad App 或浏览器管理

### 原生 iPhone/iPad App

1. 在 Windows 上打开最新 DJI 4G Assistant，并保持程序运行。
2. 让 Windows 电脑和 iPhone/iPad 连接同一可信 Wi-Fi。
3. 点击 Windows 顶部“连接 iPhone / iPad”。
4. 在 iOS App 中点击“扫描配对码”，允许相机和本地网络权限。
5. 扫描二维码后即可管理短信、eSIM、网络、电话和诊断。

App 会通过 Bonjour 自动发现主机，并把控制密码保存在 Apple Keychain。桌面版重启后密码保持不变，通常无需重复扫码；在 iOS App 菜单中选择“忘记这台电脑”可清除。

iOS 源码和云编译已包含在仓库中。GitHub Actions 会生成未签名真机 IPA 和模拟器 ZIP：模拟器 ZIP 不能装到真实设备，未签名 IPA 必须先用自己的 Apple ID 或开发者证书签名。Windows 安装、Sideloadly 测试、Xcode 和安全说明见 [iPhone/iPad 原生客户端安装说明](iOS安装说明.md)。

### 浏览器备用方式

1. 打开 Windows “系统”页显示的局域网地址。
2. 在同一可信 Wi-Fi 的手机、平板或电脑浏览器中输入该地址。
3. 输入控制密码后使用。

**127.0.0.1** 只代表当前设备自己，手机不能使用电脑的 127.0.0.1。不要把端口映射到公网。

## iPad/iPhone 直接插模块的边界

- **模块直插 iPad/iPhone 只上网：** 这是模块自己的 ECM 网卡能力，不依赖本软件。只要接口、供电和系统版本原来能识别，Windows 或 iOS 管理程序不会改变它。
- **模块直插 iPad 管理 AT/eSIM/短信/电话：** 当前原生 App 采用 Windows 主机伴侣路线，不包含通用 USB AT 驱动。Apple 的 iPadOS DriverKit 路线要求 M 系列 iPad、专用驱动扩展、Apple entitlement 和用户批准，不能靠网页或普通 App 绕过。
- **电话声音：** iPhone/iPad 可以远程拨号、接听和挂断，但 USB 通话声音仍由插着模块的 Windows 电脑处理。
- **供电：** iPhone/iPad 直连能否识别仍取决于 USB-C、转接器和供电，不是 eSIM Profile 是否兼容的问题。

## 新模块初始化

仅当程序确认是已验证的 Baiwang/QDC507 风格原始设备时使用。已成功联网的模块不要执行。

1. 运行只读检查。
2. 核对 VID/PID、`ATI`、固件和设备自己的 `usbcfg`。
3. 确认后保存本机基线，只改 VID/PID。
4. 重启并重新识别后，再单独确认 `usbnet=1`。
5. 再次插拔并扫描，确认 AT 口和 Windows 网卡都出现。

`2CA3:4006` 只是已观察到的一种身份，不代表所有 DJI 配件都相同。程序不会仅凭名称套用固定命令。

## Windows 原生与 VoHive 怎么选

| 目标 | 使用模式 | 结果 |
| --- | --- | --- |
| 在 Windows 上网、收发短信、管理 eSIM | `usbnet=1`（ECM） | Windows 看到 Quectel 有线网卡；这是本软件的默认路线 |
| 在 Linux/VoHive 中做多设备、代理或 VoWiFi 实验 | `usbnet=0`（QMI） | Linux 使用 `qmi_wwan` / `cdc-wdm`；Windows ECM 会暂时消失 |

两种模式不能同时占用。切换后模块会重启并重新枚举，COM 号也可能变化。已经在 Windows 正常上网时，不要为了“试试”切 QMI。

诊断请依次确认：

1. USB：Windows 能看到设备和真实 VID/PID。
2. 串口：出现 Quectel AT 口，程序能收到 `OK`。
3. SIM：`CPIN: READY`。
4. 蜂窝：`CEREG` 已注册，并能读取运营商与 LTE 频段。
5. 数据：PDP 已激活，模块获得 IP。
6. Windows：ECM 网卡启用、DHCP 正常，并获得 IPv4 与网关。

只有卡在哪一层，才修哪一层。不要把驱动故障当成 SIM 故障，也不要因为 Windows 没拿到地址就重新写 eSIM 或 VID/PID。

## 异常设备救援

其他工具改动后若 COM 或网卡消失，先做只读救援诊断。它检查 USB、Windows 驱动、COM、网卡、AT 口和原始接口，并保存可读取基线。完全找不到 AT 口时先检查数据线、供电、USB 和驱动；没有读取真实配置前不要盲写参数。

## 常见问题

**扫描不到模块：** 更换支持数据的 USB 线和接口，等待 Windows 驱动完成后重扫。

**LTE 已注册但 Windows 没网：** 先在“网络”页查看驱动、DHCP、IPv4 和网关。若设备是精确匹配的 `2C7C:0125 / MI_04`，且页面提示驱动需要修复，可使用“安装或修复官方驱动”。驱动正常但仍没网时，再检查 `usbnet`、PDP 和 APN；不要重复初始化模块。

**只看到一个 EID：** 点击“刷新全部 EID”，页面会自动检查标准、公开兼容和已验证私有入口。若卡商 App 明确显示多个 SE/EID，而这里只发现一个，通常表示其余空间由厂商私有切换器隐藏；请向卡商取得私有 ISD-R AID 或有文档的切换协议。不要用不明 AT 写指令反复试。套餐商订单、待下载套餐和普通 Profile 也不要当成 EID 数量。

**手机发来短信但收件箱没有：** 先看短信容量。模块达到例如 `23/23` 时可能拒绝新短信，确认并删除一条不需要的旧短信后再测试。

**短信发出但对方未收到：** “模块已接受”不等于运营商已送达。检查短信中心、国际漫游和套餐是否支持主叫短信，用已知可发短信的实体 SIM 对照。

**电话能拨号但没有声音：** 打开电话页查看“一次性声音设置”。精确匹配的 QDC507GLEFM21 先完成固定运行时下载、ADB/UAC 启用和 MI_06 WinUSB 驱动；接通后再点“启动声音”。不要在 Zadig 中替换复合设备、ECM、AT、NMEA、Modem 或音频接口。即使步骤都通过，运营商 VoLTE 或模块 DSP 不兼容时仍可能没有双向声音。

**电话点了没反应：** 软件会自动寻找 AT 口。请先输入真实电话号码，不要把输入框提示文字当成号码；拨号结果会立即显示在拨号盘下方。接听只在来电状态开放，按键音只在已接通时开放，启动声音还要求页面检测到标准 USB 音频端点。

**套餐余额不显示：** 这是标准字段限制，需要套餐商 API。

## 桌面版和源码版的区别

普通用户请运行 Releases 中的 Windows EXE。拨号、接听、挂断和只读刷新等日常操作直接执行；eSIM 删除、USB 模式、原始模块转换等高风险操作仍会要求确认。

开发者直接运行 `npm start` 时默认是只读服务，因此切换套餐、下载套餐、发送短信、电话控制、短信删除和声音设置可能处于锁定状态。这是安全保护，不是功能缺失。双击源码中的 `Start-Web-Console.cmd` 会开放完整本地控制台，并为本次启动自动生成带密码的本机和局域网地址；电话等日常操作直接执行，USB/ADB/UAC 等高风险操作仍需确认，关闭窗口后临时密码失效。
