# DJI RoamDock Pro for Windows 中文使用说明

这是给 Windows 用户的完整本地网页管理工具。适合新模块、原始 2CA3:4006 模块，或需要 USB 网卡改造、短信发送、完整诊断和 eSIM 管理的用户。模块插在 Windows 电脑上，网页管理台在这台电脑上运行；可以直接用电脑浏览器操作，也可以让同一 Wi-Fi 下的手机、平板或另一台电脑打开管理页面。

已经改好、已是 2C7C:0125 + usbnet=1，只需要状态查看和基础 eSIM 管理的模块，可以使用更轻量的 [DJI RoamDock Lite for Windows](https://github.com/Northfish0311/DJI_RoamDock-Lite-for-Windows)。

## 直接使用`r`n`r`n项目只保留一个启动文件：`Start-Web-Console.cmd`。插入模块后双击它即可。
## 第一次使用

1. 安装 [Node.js LTS](https://nodejs.org/)。
2. 下载或克隆本项目，在项目文件夹中运行一次 `npm install`。
3. 插入 DJI Cellular Dongle 或兼容 USB 4G 模块。
4. 双击 `Start-Web-Console.cmd`，保持黑色窗口打开。
5. 在这台 Windows 电脑的浏览器打开 `http://127.0.0.1:8787`。
6. 点击网页里的“自动扫描”。

黑色窗口会同时打印局域网地址，例如 `http://192.168.1.20:8787`。该地址可由同一 Wi-Fi 下的手机、平板或另一台电脑打开；每台 Windows 电脑的局域网地址不同。

## 网页里能做什么

### 自动扫描与状态

“自动扫描”会查找 USB 设备、COM 口、模块型号、SIM 状态、运营商、信号、注册状态、APN、PDP 和 Windows 网卡。扫描没有修改模块配置。

### eSIM 管理

首次使用 eSIM 功能，先运行 `Install-eSIM-Tools.cmd` 下载官方 `lpac` 工具。随后可在网页查看实体 eUICC 卡片的 Profile，启用或停用已有套餐，或粘贴自己购买的完整 `LPA:1$...` 激活码下载新套餐。

下载和启用都会改动卡片，因此网页会要求确认。下载新套餐不会删除已有 Profile；本项目没有提供删除 Profile 的按钮。写入过程中不要拔出模块。

### 短信

网页可读取模块收到的短信，也可手动发送短信。发送时必须填写收件号码和内容，国际号码使用例如 `+86138XXXXXXXX` 的格式。短信并非自动转发，是否收费、能否发送取决于运营商、套餐和漫游状态。

### 原始模块设置

如果扫描结果是兼容原始身份 `2CA3:4006`，网页会出现“Original Module Setup”。先执行只读检查；确认设备信息后，页面才允许两阶段设置：先切换到 `2C7C:0125`，重新插拔识别后，再设置 `usbnet=1`。

这两步都需要输入确认词，且程序会先保存本机基线。已经能正常使用的模块不要重复执行。其他 VID/PID 的设备不会因为名称相似就自动写入。

## 地址与安全

- `http://127.0.0.1:8787` 只能在启动它的 Windows 电脑上打开。
- `http://192.168.x.x:8787` 是局域网地址，只能在同一可信 Wi-Fi 下使用。
- 不要把这个地址暴露到公网，也不要放在无密码的公网穿透服务中。
- 家里自用 Wi-Fi 一般不需要额外设置。公司、酒店或公共 Wi-Fi 建议给网页加密码，避免同网设备看到短信和 eSIM 信息。

设置方法：在项目文件夹空白处右键，选择“在终端中打开”或打开 Windows PowerShell，依次运行：

```powershell
$env:CONSOLE_TOKEN = "你自己设定的密码"
.\Start-Web-Console.cmd
```

随后在网页右上角的“Console Token / 控制台密码”输入同一密码。这个密码只对本次启动有效；关闭黑色窗口后，下次需要重新设置。

## 常见问题

**网页打不开：** 确认黑色启动窗口没有关闭；本机用 `127.0.0.1`，其他设备用窗口显示的 `192.168.x.x` 地址。

**没有扫描到模块：** 换支持数据传输的 USB 线或 USB 口，重新插拔后再点“自动扫描”。

**eSIM 页面没有功能：** 先运行 `Install-eSIM-Tools.cmd`，并确认模块的 AT COM 口已被 Windows 正常识别。

**短信或流量不能用：** 先看 SIM 状态、网络注册、信号和套餐本身。软件不会绕过运营商套餐、漫游或账户限制。
