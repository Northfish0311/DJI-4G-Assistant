# 大疆 4G 助手 1.8.2

## 普通用户怎么用

1. 下载 **DJI-4G-Assistant-Setup-1.8.2-x64.exe**。
2. 先退出旧版，再双击下载的文件，按提示安装。
3. 插好 SIM 和模块，双击桌面的 DJI 4G Assistant，等待自动识别。

不需要安装 Node.js、运行启动脚本或手填网址。不想安装可选 `Portable-1.8.2-x64.exe`，双击即可运行；两个版本功能相同，不要同时打开。`SHA256SUMS.txt` 用于校验，`Source code` 是开发源码，普通用户不用下载。

本项目没有商业代码签名证书，Edge 或 Windows 可能显示安全提醒。先确认文件来自本仓库并核对校验值，不要关闭系统安全防护。

## 这次更新

本版只改内部实现，界面和操作方式与 1.8.1 相同。

- 状态查询改为读取驱动：模块回 `OK` 就继续，不再每条指令固定等待 450 毫秒。
- 新增常驻 PowerShell 主机，省掉每次请求重新启动进程的开销；短信、USSD 等长任务使用独立的第二个主机，不会拖慢通话状态刷新。
- 读取通话能力时的设备枚举改用更快的查询方式，并对结果做 8 秒缓存；启用或恢复 USB 配置、安装驱动后立即失效。
- 三条 USB 配置流程（原厂模块 USB 网络模式、通话 USB 启用、通话 USB 恢复）改为各自一次串口事务，写入、回读和重启之间不会被后台状态刷新打断。
- 指令超时后结束整棵进程树，避免残留进程占住串口，导致下一次读取报“无法打开端口”。

## 实测数据

同一台 Windows 电脑、同一个 QDC507 模块，三轮取中位数，只发只读查询：

| 操作 | 1.8.1 | 1.8.2 |
| --- | --- | --- |
| 启动状态查询 | 4.96 秒 | **0.38 秒** |
| 通话状态轮询 | 0.46 秒 | **0.13 秒** |
| SIM 卡状态 | 0.45 秒 | **0.10 秒** |
| 模块温度 | 0.49 秒 | **0.16 秒** |
| 通话能力页首次加载 | 约 11.6 秒 | **0.7–2 秒** |

**这不是完整软件启动时间或上网速度保证。** 模块、固件、驱动和电脑不同，结果也会不同。测量方法见[性能记录](https://github.com/Northfish0311/DJI-4G-Assistant/blob/main/docs/PERFORMANCE-NOTES.md)。

## 已验证与未验证

- 273 项自动测试通过，语法检查通过。
- 实机验证覆盖启动状态查询、卡状态、温度、通话状态和通话能力读取，数据与 1.8.1 一致。
- 本轮**没有**发送短信、拨号、写入 eSIM 套餐或切换 USB 模式；这些流程的代码路径已通过自动测试覆盖，但未在实机上执行。

## 驱动提醒

只有网卡、没有 AT 串口时，模块可能能上网，但助手无法读取短信或管理 eSIM。**安装本软件不会自动修复缺失或错误的串口驱动。** 请按 [Windows 驱动说明](https://github.com/Northfish0311/DJI-4G-Assistant/blob/main/docs/Windows%E9%A9%B1%E5%8A%A8%E8%AF%B4%E6%98%8E.md)检查，不要盲目改 USB 模式、APN 或套餐。

升级本软件不会自动改变模块 USB 配置或卡内套餐。发布页只保留最新版安装包，源码提交历史保留。
