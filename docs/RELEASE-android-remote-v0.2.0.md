# 安卓远程助手 0.2.0（测试版）

配合 Windows 助手使用的安卓远程客户端。模块仍插在 Windows 电脑上，电脑保持运行；手机与电脑连接同一可信局域网后扫码配对。**不是**模块直插手机的独立版。

## 安装

1. 用安卓手机下载[0.2.0 测试版 APK](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/android-remote-v0.2.0/DJI-4G-Remote-Android-0.2.0-test.apk)，或从电脑传到手机。
2. 点开 APK 安装。如系统询问，仅允许当前下载来源「安装未知应用」，无需关闭安全扫描。
3. 在 Windows 助手点「连接手机 / 平板」，用手机 App 扫描二维码。

这是调试签名测试包，不是应用商店正式版。不想安装 App，也可以用手机浏览器打开 Windows 助手「系统」页显示的局域网地址。

## 功能

- 扫码配对、Bonjour 自动发现（`_dji4g._tcp`）、手动填写地址
- 设备状态、eSIM、短信、通话、网络各页面的远程操作
- 手机使用五个底部入口，平板使用侧栏布局
- 管理页面加载失败时，按 1、2、4 秒间隔最多重试三次；授权错误不重试，也不会自动重发短信或切换套餐。

## 限制

- 电脑程序关闭、电脑休眠或不在同一局域网时无法使用
- 不支持模块直插手机独立管理短信、eSIM、网络或电话
- 需要 Android 7.0（API 24）及以上

## 验证边界

界面截图来自模拟器，自动化测试覆盖配对地址解析、配对历史与重连策略。**真机扫码、相机与本地网络权限弹窗、锁屏后恢复仍需自测**；模拟器通过不代表真机已验证。

Edge、Windows 或手机安全软件可能提示文件不常见。请只从本仓库下载，可用同一发布页的 `SHA256SUMS.txt` 对照 APK 的 SHA256。
