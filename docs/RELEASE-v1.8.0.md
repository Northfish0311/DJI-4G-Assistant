# 大疆 4G 助手 v1.8.0

## 下载与安装

普通用户下载 `DJI-4G-Assistant-Setup-1.8.0-x64.exe`，先退出旧版，再双击安装即可。
`Portable` 是免安装版；`SHA256SUMS.txt` 用于校验；`Source code` 是开发源码，不需要一起下载。

软件尚未购买商业代码签名，Edge 或 Windows 可能显示发布者/信誉提醒。请核对来源为本仓库，不要关闭系统安全防护。

**v1.7.17 的下载与说明保持原样，不受影响。**

## 这次改了什么

### 前端代码按功能域拆分为 10 个文件（本版唯一改动）

原来的界面脚本是单个约 166 KB 的文件，改一处要在大文件里翻，出问题也难定位。现在按功能拆开，各自职责清晰：

| 文件 | 负责范围 |
|------|----------|
| `core.js` | 页面元素引用、全局状态、多语言入口、日志与通用工具 |
| `euicc.js` | eSIM 卡库、芯片信息、发现流程、Profile 与通知列表 |
| `sms.js` | 短信读取/解析/发送、搜索高亮、流量统计、连接状态 |
| `calls.js` | 通话状态文字、通话历史、语音网络、语音环境安装向导 |
| `audio.js` | 音频设备识别、模块语音路由、通话音频桥接 |
| `call-flow.js` | 拨号后流程、通话状态渲染、通话动作与会话按钮同步 |
| `api.js` | 与服务端通信的传输层 |
| `automation.js` | 自动扫描、快速开始、模块卡片监控、AT 指令发送 |
| `profile-actions.js` | Profile 启用/删除/下载/改名、USSD、USB 模式、驱动安装、配对 |
| `init.js` | 定时刷新、事件绑定、视图切换与启动流程 |

**这是纯结构调整**：功能、界面、按钮位置、中英文文案、通话逻辑全部不变，不会改变你的使用方式。v1.7.17 修复的全部问题都保留在本版中。
