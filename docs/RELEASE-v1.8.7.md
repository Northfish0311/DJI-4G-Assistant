## 这次改了什么

- **优先走 Wi-Fi**：先连 Wi-Fi，再插模块，打开桌面版「网络 → 优先使用 Wi-Fi」。只调整识别到的那张大疆 ECM 网卡，不改 SIM、APN 或 DNS。可在同一处恢复原优先级。Wi-Fi 断开仍可能使用卡流量；手机或普通网页不能改电脑网卡。
- **看清流量走哪儿**：网络页分别列出 Windows 默认 IPv4 出口和正在统计流量的模块网卡。默认出口不代表所有 VPN 或特定目标的流量路径。
- **短信**：长会话先显示最近 40 条，可加载更早内容；搜索会匹配已读取的整个会话。Windows 在串口空闲时监听新短信通知，仍保留定时补查。模块短信仓库用到 80% 以上时，容量提示条会多出「清理旧短信」：先问你保留最新的几条（1–50），确认后批量删除更早的消息，删完会告诉你实际清掉几条、剩下几条。模块返回的短信列表不完整时一条都不会删，避免删错；单条删除仍然照旧可用。
- **隐私与声音**：eSIM 卡号默认只露出末六位。通话时可分别查看麦克风和模块下行的声音活动，这不代表对方一定能听见。
