# 大疆 4G 助手 v1.7.15

## 下载与安装

普通用户下载 `DJI-4G-Assistant-Setup-1.7.15-x64.exe`，先退出旧版，再双击安装即可。
`Portable` 是免安装版；`SHA256SUMS.txt` 用于校验；`Source code` 是开发源码，不需要一起下载。

软件尚未购买商业代码签名，Edge 或 Windows 可能显示发布者/信誉提醒。请核对来源为本仓库，不要关闭系统安全防护。

## 这次改了什么

- **短信正文更完整：** 修复正文中出现 `OK`、以 `OK` 开头的行或不完整 `+CMGL:` 文字时被截断、误解析的问题。保留原有 UCS2 中文解码。
- **搜索结果更直观：** 显示匹配会话数量；列表预览命中的短信，不再只显示最新一条；号码和正文关键词高亮。
- **阅读定位更顺手：** 点击搜索结果定位首个正文匹配处，自动刷新不反复跳转；清除搜索不丢会话草稿。
- **布局与说明：** 搜索框统一图标、间距和清除按钮，补充中文使用步骤。旧移动端测试包已移除，说明改为推荐手机浏览器连接 Windows。

搜索、预览和高亮都在本机完成，不上传短信。发布页只保留最新 Windows 正式版，源代码及提交历史保留。

## 验证范围

- 新增短信解析及搜索回归用例，覆盖正文内 `OK`、伪指令文字、空短信、UCS2、多条记录、特殊搜索字符和 HTML 转义。
- 页面在 1440、1024、390、320 像素宽度完成截图与交互检查；检查中英文、搜索、清除、草稿、阅读位置及刷新失败恢复。
- 对已连接模块完成短信只读实测，读取、搜索与再次刷新正常。

本轮未发短信、未删除短信、未切换 eSIM、未修改 USB 模式、未进行真实通话。短信解析修复不等于运营商送达保证；电话声音仍属实验功能，流量统计不是套餐剩余量。
