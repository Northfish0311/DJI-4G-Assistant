# Windows 驱动说明

## 要不要另外装驱动

**不一定。** Windows 已自动装好对应驱动时，插模块、打开助手即可。没有装好时，安装助手本身不能代替安装硬件驱动。

| 你要做什么 | 需要什么 |
| --- | --- |
| 用模块上网 | 正常工作的 USB 网卡驱动 |
| 读取短信、eSIM、模块状态或控制电话 | 正常工作的 AT 串口驱动 |
| 通话声音 | 另外还取决于语音接口、模块固件、运营商和套餐；有 AT 口不等于声音可用 |

## 能上网，但助手找不到模块

1. 保持模块插着，先关闭其他串口工具或重复打开的助手。
2. 右键 Windows 开始按钮，打开“设备管理器”。
3. 展开“端口（COM 和 LPT）”，查看是否有类似 **Quectel USB AT Port (COM 数字)** 的条目。COM 号因电脑而异，不必和别人相同。
4. 如果有 AT 口，重新打开助手，必要时点击一次“自动扫描”。蓝牙串口不算模块 AT 口。
5. 如果只有网卡、黄色感叹号，或相关接口显示 WinUSB/Baiwang USBDevice 而不是串口，先处理对应驱动，不要改 APN、套餐或模块 USB 模式。

## 去哪里下载

- [移远 EC25 官方产品与下载页](https://www.quectel.com/product/lte-ec25-series/)：提供对应驱动及安装资料，部分下载需要登录。
- [移远官方论坛的 Windows USB 驱动附件](https://forumschinese.quectel.com/t/topic/4291/4)：包含 `Quectel_Windows_USB_Driver(Q)_NDIS_V2.7.9.zip`。它是完整驱动包，**不代表所有接口都应该安装 NDIS 驱动**。

只有确认设备和驱动的硬件 ID 匹配后才安装。品牌名称或外壳相似，不等于内部模块相同。原始设备也不一定是 `2CA3:4006`。

对于已核对的 `2C7C:0125` USB 身份，官方 `qcser.inf` 的串口定义包括 MI_02（AT）、MI_01（NMEA）和 MI_00（DM）。这只是匹配依据，不是让所有用户强制改成这个 VID/PID。

## 已经改成 WinUSB 怎么办

如果之前用工具把 AT 接口绑定成 WinUSB，只把驱动安装包下载下来不会恢复串口。需要先备份原绑定，再为匹配的 AT 接口选择有有效签名的官方串口驱动。**当前助手没有自动完成这项恢复的按钮**，也不会后台静默修改驱动。

如果 ECM 网卡已经能上网，不要直接安装整个 NDIS 驱动包，不要批量卸载所有 Quectel/Baiwang 接口。保留网卡、ADB 和声音接口，只恢复已确认错误的串口绑定。操作前在“详细信息 → 硬件 ID”核对目标；不确定时先保留诊断结果，不盲目强制安装。

本次验证的官方串口目录中，`qcser.cat` 有 Microsoft Windows Hardware Compatibility Publisher 有效签名，x64 `qcusbser.sys` 也有有效签名。安装器外壳是否签名和内部驱动是否签名不是同一个问题；不要关闭 Windows 的驱动签名强制检查。

## 修好后看什么

重新打开助手，确认能自动找到 AT 口，概览能读取 SIM 状态，再分别打开短信或 eSIM 页面。驱动修好不会自动激活套餐、充值、修复短信送达或保证通话声音正常。

项目不附带这次本机维修脚本、驱动备份、卡号或设备日志，也不重新分发第三方驱动包。
