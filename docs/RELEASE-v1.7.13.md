# 大疆 4G 助手 v1.7.13

## 下载与升级

普通 Windows 用户下载 `DJI-4G-Assistant-Setup-1.7.13-x64.exe`。先退出旧版，再安装新版；无需 Node.js 或命令窗口。

`Portable` 是免安装版，`SHA256SUMS.txt` 是校验清单，`Source code` 是开发者源码。项目尚无商业代码签名，只从本仓库下载并核对文件，不要关闭系统安全防护。

## 修复与改进

- eSIM 读取失败、服务错误或内容不完整时，保留已有卡库、套餐列表和未保存昵称，不再把读取失败当成空列表。
- 成功刷新后清除错误状态；真正读到空列表与读取失败分别处理。普通实体 SIM 没有 EID 时仍正常提示能力差异。
- 丢弃换卡、改端口或切换 EID 之前发出的延迟回复，防止旧结果覆盖当前页面。
- 写卡已成功但后续刷新失败时单独提示，保留旧列表并建议刷新核对，不诱导重复写入。
- 中途断线或写入回复无法解析时显示结果未知、保留激活码，不自动重试。前一个下载完成也不会清空后来新填写的激活码。
- 写入后的内部刷新不会提前解除忙碌状态；刷新失败会显示在对应页面，避免错误提示出现在无关页面。
- 短信读取必须收到列表指令的完整成功回复，不能拿前面设置命令的 `OK` 当作读取成功。错误或不完整回复保留现有短信，自动扫描同样处理。
- 来电和通话期间暂停后台短信轮询，结束后按原设置恢复。

## 验证范围

新增自动测试覆盖读取错误、正常空列表、换卡延迟回复、写入成功后的刷新失败、断线时的未知结果，以及短信读取最终状态。浏览器使用虚构数据检查 1440、1024、390、320 像素宽度的提示、草稿保留和恢复流程。

发布前会启动打包后的服务，检查页面、认证和内置 eSIM 工具文件。本次不对真实模块发短信、拨号或写卡；不把自动测试当成运营商投递和稳定双向通话的验证。通话声音仍属实验功能。
