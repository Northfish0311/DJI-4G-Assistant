# Windows 界面优化

套餐管理与短信阅读优化从 Windows v1.7.11 提供；本文中的“AT 工具与日志”“网络状态”以及工具页布局调整随 Windows v1.7.12 提供。

v1.7.13 继续补充读取失败恢复、旧卡延迟回复隔离，以及写入结果与刷新结果的分别提示。

v1.7.14 优化实时流量采样、连接地址判断和配对失败窗口。

## 套餐管理

1. 打开 eSIM，选择要查看的卡片空间。
2. 在搜索框输入套餐名称、运营商或卡号的一部分。多个词以空格分隔时，结果需同时匹配这些词。
3. 在右侧选择全部、已启用或未启用。结果数只统计当前 EID，卡片空间的总数不会被搜索改变。
4. 点击搜索框右侧的叉号清除关键词；套餐状态筛选不变。
5. 展开“更多操作与卡号”后可编辑套餐昵称。列表刷新、切换语言或查看另一个 EID 不会丢弃未保存的内容。

搜索、筛选和展开详情均不会启用、停用或下载套餐。未保存的昵称、筛选条件和展开状态仅存在当前页面内存中，不保存到磁盘或浏览器存储。关闭页面或检测到换卡后清除。卡内昵称仍需要点击“保存”并确认才会修改。

套餐剩余流量没有通用卡内读取接口，本次没有将网卡流量冒充套餐余额。

读卡失败或返回内容不完整时，不清空现有卡库、套餐和未保存昵称。顶部显示未读到有效结果；点刷新成功后更新数据并清除提示。换卡或切换 EID 后到达的旧回复不更新当前页面。

写入已成功但后续刷新失败时，会明确提示“写入已成功，但列表刷新失败”。此时显示的是上次列表，请刷新确认，不要重复写入。请求中途断线时结果未知，也不会自动重试。写入后的内部刷新不会提前解除外层操作的忙碌状态。

## 短信阅读

- 位于会话底部时，新消息自动显示在底部。
- 向上查看历史消息时，刷新会尽量保留同一条短信及其屏幕位置，不强制跳到底部。
- 新读到的记录以“新短信”按钮提示，点击跳到底部；手动滚动到底部也会清除提示。
- 当前会话、回复草稿和会话列表位置继续保留。读取失败只提示错误，不清空收件箱；下一次成功读取后恢复正常状态。
- 这里只保留当前模块读到的记录，不新增短信云同步，也不新增自动发送行为。
- 短信列表必须收到完整的最终成功回复；此前设置指令返回的 `OK` 不能代替列表读取成功。模块错误或回复不完整时保留已有短信，不当成空收件箱。
- 接打电话时暂停后台短信轮询，结束后按原轮询设置恢复，避免额外争用串口。

## 布局

统一套餐搜索框和状态选择框高度、详情区域间距及标题字号；套餐名称与运营商相同时不再重复显示。短信正文增加行距，新消息按钮固定在阅读区内，不挤动回复输入框。窄屏的筛选控件改为纵向排列。

网络、系统和 AT 页：网卡名称单独一行，下载与上传用不同颜色区分，速率、累计流量和连接信息分组对齐；系统页标题、字段和检查按钮采用一致的左边线。AT 发送按钮、日志工具都有对应图标和中文悬停名称。

## AT 工具与日志

1. 打开“AT 工具”，输入已知的只读指令，例如 `AT+CSQ`，点击“发送”。
2. 页面显示等待、成功或失败，下方自动展开返回日志。等待期间重复点击或按回车不会重复提交。
3. 向上滚动日志时，自动停止跟随，新记录数量会显示在工具栏下方。点击向下箭头或勾选“跟随最新”回到最新记录。
4. 点击复制图标，将当前保留的日志复制到本机剪贴板；点击垃圾桶图标只清空页面日志，不删除模块里的短信、套餐或配置。

日志只留在当前页面内存中，最多 200 条、合计 200,000 个字符，单条过长会截短并标注。达到限制时清理较早记录，防止长时间运行后页面越来越卡。清理或关闭页面后不能从这里找回。每个页面分别记住日志的展开状态，进入 AT 页自动展开，不会把网络、系统等页面的日志一起展开。

复制不会上传日志；但日志可能含号码、短信、EID、ICCID 等个人信息，公开分享前请自行删去。浏览器不允许复制时会明确提示手动选中文字复制，不会显示虚假的“复制成功”。

请求超过 90 秒时停止等待，恢复操作按钮，不自动重发。超时不代表后台串口操作一定未执行；请先检查结果再重试。危险指令的服务端拦截不变。

## 网络状态

- 刷新失败时，实时下载和上传速率显示 `--`，保留上次连接信息和累计量，并明确标注它们是旧采样，不把旧速度冒充当前速度。
- Windows 网卡断开时显示断开提示，不把 `0 B/s` 当成仍在正常采样。重新连接后，收集到两次有效采样再显示速度。
- 后台读取仍有失败退避，不会连续高频重试。恢复有效采样后自动更新。
- 这些数据只反映 USB 网卡流量，不代表套餐剩余流量，也不能单凭网卡已连接判断外网一定可用。
- 首次完整查询后，自动刷新只快速读取计数器；网卡标识、连接状态或地址变化时重新查询。完整资料每分钟更新一次，手动刷新立即重读。不同浏览器共享进行中的采样，不叠加多个查询进程；快速读取不支持时回退到完整查询。

## 手机连接窗口

仅监听本机时显示“仅本机访问”，不生成局域网配对码。没有合适的 Wi-Fi 或有线局域网时，直接显示连接条件与刷新按钮，不再留下一块空二维码。失败状态不显示绿色就绪标记，也不能复制旧配对链接；恢复网络后可在窗口内点击刷新重试。

地址自动推荐会避开模块常见的 USB 网段及常见虚拟网卡。二维码只表示已生成配对信息，不代表已验证手机可穿过 Windows 防火墙或访客网络隔离。

## 验证边界

自动测试使用虚构的 EID、套餐、短信和网卡数据，检查多 EID 状态隔离、筛选、备注草稿与光标、刷新失败恢复、日志阅读位置、重复提交、AT 错误和超时以及响应式布局。测试不向真实模块写入配置，不发送短信，不切换套餐，也不代表运营商通话或真实硬件兼容性新增通过。

v1.7.14 另对一块已连接模块完成只读实测：网络注册、eSIM 多 EID 与套餐列表、短信读取、网卡和流量计数器均正常返回。没有更改 USB 模式、切换套餐、发送短信或进行通话。
