# 大疆 4G 助手 1.9.3 · Windows 64 位

先退出旧版。[安装版（推荐）](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/v1.9.3/DJI-4G-Assistant-Setup-1.9.3-x64.exe) 与[免安装版](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/v1.9.3/DJI-4G-Assistant-Portable-1.9.3-x64.exe) 二选一。下载后双击，不需要另装运行环境。

## 这次改了什么

**「禁止大疆流量」不再卡半分钟。**

1.9.2 里这个功能是有的，但点一下要等三十多秒——查设备、查状态、改状态各走了一遍 PnP 接口，而这台机器上每个 PnP 调用都要约 11 秒（它们每次都遍历整棵设备树）。

现在改成直接问设备管理器底层接口：

| 步骤 | 改前 | 改后 |
| --- | --- | --- |
| 找模块网卡 | `Get-PnpDevice` 约 11 秒 | 读注册表约 0.1 秒 |
| 读当前状态 | `Get-PnpDeviceProperty` 约 11 秒 | 单节点状态查询约 0.04 秒 |
| 停用 / 启用 | `Disable/Enable-PnpDevice` 约 11 秒 | 直接调用，毫秒级 |
| 点一次「禁止」总计 | 约 33 秒 | 不到 1 秒 + 管理员确认 |

判断逻辑没有放松：实例必须精确匹配、多于一个就放弃、只接受「正常」或「已停用」两种状态、停用前必须有可用的 Wi-Fi 默认路由、操作后轮询确认状态真的变了，取消管理员授权会按「已取消」处理而不是报错。

## 验证方式

本机实测 Check 模式：改前约 11 秒，改后冷启动 2.2 秒（其中约 1.5 秒是 PowerShell 启动与编译），在程序常驻进程里为毫秒级；取消管理员授权返回 15。fixture 覆盖钉死目标、Wi-Fi 守卫、重复点击幂等、异常设备拒绝四种情形，全部通过；全量 346 项测试通过。

## 验证边界
