# 大疆 4G 助手 v1.7.12

## 下载与升级

普通 Windows 用户下载 `DJI-4G-Assistant-Setup-1.7.12-x64.exe`，先退出旧版，再安装新版。无需安装 Node.js，也不用运行黑色命令窗口。

- `Portable` 是免安装版，双击即可运行。
- `SHA256SUMS.txt` 用于核对下载文件；`Source code` 是开发者源码，不是安装包。
- 项目尚无商业代码签名，Edge 和 Windows 可能提醒不常见应用。只从本仓库下载，不要关闭系统防护。

## 本次改进

- 网络页重新整理网卡、下载/上传和地址布局，系统页表单对齐，窄屏保留正常间距。
- 网络刷新失败时保留上次总量和地址，隐藏过期速度；断线状态不再冒充实时零流量。
- AT 工具发送后显示结果并展开日志。日志支持暂停跟随、跳到底部、复制、清空和有界保留，阅读时不再被强制滚动。
- 修复 AT 进程退出但没有完整 `OK` 回复时误报成功；超时不会自动重发。
- 修复 eSIM 下载返回失败却清空激活码、刷新成成功状态的问题。只有确认成功才清空输入；结果未知时提示先核对套餐列表。
- 下载、启用/停用、改昵称、处理通知和删除前重新读取目标 EID。换卡、读取失败或通话状态不明时停止写入。
- 接听/挂断不再因后台读取而直接被禁用；呼叫指令优先排队。已经开始的任务不会强行打断，排队超时的命令不会延迟执行。
- 源码启动默认仅本机访问；局域网监听必须设置控制密码。Windows EXE 自动配置，普通用户无需设置。
- 固定官方 lpac v2.3.0，并在解压前校验 SHA-256。发布流程增加安装包内容、实际服务启动、页面文件和认证检查。

## 验证范围

自动回归覆盖错误回复、换卡写入保护、队列优先级/超时、来电按钮、网络故障和日志阅读；浏览器检查覆盖桌面和窄屏布局。发布流程还会在无模块环境启动打包后的服务，检查页面、认证和 eSIM 工具文件。

这些检查不等于运营商通话、真实短信投递或真实 eSIM 下载已经完成实测。本次不会自动修改模块 USB、APN、IMS 或套餐；通话声音仍属实验功能。手机和平板仍通过 Windows 远程管理，不是直插独立版。
