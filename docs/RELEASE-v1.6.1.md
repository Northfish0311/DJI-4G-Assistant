# DJI 4G Assistant v1.6.1

## Windows 用户怎么用

优先下载 **Setup** 安装版，安装后打开桌面上的 DJI 4G Assistant。**Portable** 为免安装版，直接运行即可。两者功能相同，不需要另装 Node.js，也不用手动开启命令行。Source code 是源码，不是给普通用户直接运行的安装包。

插上模块并打开软件，等待自动识别，再从左侧进入短信、电话、eSIM 或网络。下载包未进行商业代码签名，Edge 或 Windows 可能提示风险；请核对仓库地址和 SHA256，不要为了运行软件关闭系统安全保护。

## 这次更新

- 修复 ESTK SE0 / SE1 双 EID 入口遗漏；按 EID 分组读取套餐，重复入口不会重复计数。
- 修复旧版 lpac 串口参数兼容性，eSIM 与短信、AT 查询使用同一串口队列。
- 启动时自动读卡，检测到模块或 SIM 标识变化后清除旧数据并重新识别。
- Windows 侧栏导航、字体、套餐卡片和常用入口更新；卡号、改名和删除折叠到“更多操作与卡号”。
- 修复打开 eSIM 页不自动加载的问题；读取失败不再误显示为 0 个套餐。

## 支持范围

**只处理标准入口和已经适配的厂商入口。未知私有入口不猜、不自动切底层芯片。**

当前已实测 ESTK 双 EID 读取；其他品牌能否读全，取决于它是否开放标准或已适配入口。只读到一个 EID 不等于该卡只有一个。未知入口暂不支持；通信错误显示读取失败，不会当作空卡，也不会自动重置、改 USB 或切套餐。

自动读取已做实卡验证；电话、短信发送和套餐写入的结果还受套餐、运营商及设备能力影响。本次读卡验证没有切换套餐或修改模块配置。
