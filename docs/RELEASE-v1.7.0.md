# DJI 4G Assistant v1.7.0

本次更新集中改善日常使用、电话声音选择、eSIM 切换核对和手机远程管理体验。

## 下载

普通用户下载 **Setup** 安装版；需要免安装运行时下载 **Portable**。两者功能相同，包含运行所需依赖。可使用同页的 `SHA256SUMS.txt` 核对文件。

## 更新内容

- 重新整理桌面和窄窗口布局，短信、电话、eSIM 页面在常见桌面与移动宽度下更清楚；手机端优先显示总览、短信、电话和 eSIM，其他工具仍可横向访问。
- 总览增加 Quectel 模块温度。只在空闲的总览页低频读取，通话、设备写入或不支持 `AT+QTEMP` 时自动暂停。
- 启用 eSIM Profile 后，只读核对当前 ICCID 和 IMSI，区分切换成功、网络仍在注册、卡号尚未变化；不会自动重启模块或重复切换。
- 电话支持 `主号,,分机#` 延时分机格式；通话接通后逐个发送 DTMF，挂断或失败后停止，不会盲目重试。
- Windows 通话声音可分别选择麦克风和扬声器，并记住选择；模块 UAC 输入和输出仍由程序自动匹配。
- AT 口自动发现会优先尝试 Quectel/QDC507/USB Modem 端口，并在设备刚插入时等待后重试；蓝牙串口继续忽略。
- Android 远程客户端保存上次配对主机并在网络恢复时自动重连；iOS 实验性远程客户端改善连接状态、重试提示和配对文案。

## 验证范围

- 65 项项目测试和 JavaScript 语法检查通过。
- `1440px`、`1280px`、`1024px` 和 `390px` 布局截图检查通过，无横向溢出；测试过程未触发设备写入。
- 实机已读取到 QDC507 `AT+QTEMP` 返回并解析温度。本轮 AT 自动发现测试时串口未回复，可能被其他程序占用或尚未枚举，因此没有把该次扫描写成成功实机结论。

eSIM Profile、短信送达、语音和双向声音仍取决于实际模块、卡片、Windows 驱动及运营商支持。高风险 USB/ADB/eSIM 删除操作继续保留确认，未知设备不会自动套用配置。
