# DJI 4G Assistant v1.6.2

本次更新改善 Windows 桌面端的短信、电话和 eSIM 操作流程。

## 下载

普通用户下载 **Setup** 安装版；需要免安装运行时下载 **Portable**。两者功能相同，包含运行所需依赖。可使用同页的 SHA256SUMS.txt 核对文件。

## 更新内容

- 短信按号码分组，支持搜索、直接回复和新建短信；每个会话分别保留草稿。后台刷新不打断输入，失败后保留现有短信并提供重试。
- 发送前在页面内核对号码和内容；发送失败保留草稿，成功后显示模块接受结果，不将其当作送达回执。发送期间继续编辑的内容不会被清空。
- 电话页根据连接、控制权限和读取结果提示下一步。来电时显示接听控件；声音设置按需展开，并提示准备进度。状态读取失败保留上次通话状态。
- eSIM 空间选择区更紧凑，已启用套餐优先显示；卡号、容量和高级操作可展开查看。选择 EID 只改变查看对象，启用或停用前会确认目标 EID 和套餐。
- 统一桌面配色、导航和反馈，保留中英文及窄窗口布局。

## 验证范围

50 项项目测试、语法检查及四种窗口宽度的中英文模拟交互检查通过。本轮未进行真实设备回归，电话声音、短信发送和套餐写入仍取决于实际模块、卡片及运营商支持。

草稿只保留在当前页面内存，关闭页面或检测到卡片变化后清除。原有设备写入限制及高风险操作确认仍然有效。发布包没有商业代码签名，请从本仓库下载。
