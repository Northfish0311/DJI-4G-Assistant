# iPhone / iPad 远程管理 v1.0.1

这是独立于 Windows 1.6.2 的实验性远程客户端，不是模块直插 iPhone/iPad 的独立管理版，也不是 App Store 正式版。

## 下载哪个

- **Unsigned.ipa**：真实 iPhone/iPad 的未签名 App，需要有效 Apple 签名后才能安装，不能直接点开安装。适合了解侧载流程的测试用户。
- **Simulator.zip**：只供 Mac 的 iOS 模拟器使用，不能安装到手机或平板。
- **SHA256SUMS.txt**：下载校验文件，不需要安装。
- **PNG 图片**：构建期间生成的配对页面截图。

不想处理签名的用户，直接用 Safari 打开 Windows 助手显示的局域网管理地址即可，无须安装此 App。

## 使用条件

1. 模块插在 Windows 电脑上，电脑助手保持运行。
2. 手机或平板与电脑连接同一可信局域网。
3. 已安装并签名的 App 扫描电脑助手的配对二维码，首次允许相机和本地网络权限。

App 支持网页确认与输入弹窗、附近电脑地址填入，以及页面加载失败后的有限次数重连。不会自动重发短信或重复套餐写操作。电话控制不代表通话声音可以传到手机。

HTTP 局域网连接不等于加密连接，不要映射管理端口到公网。配对密码存于 Keychain，忘记电脑会移除保存的配对信息。

发布流程要求模拟器构建、配对链接单元测试、iPhone/iPad 配对页截图及未签名真机包构建全部成功。它们不等于实际模块、相机扫码、短信/eSIM 写入或电话音频已通过真机测试；这些仍需验证。

完整步骤见仓库 `docs/iOS安装说明.md`。本次发布不更换 Windows 安装包，也不修改模块配置。
