# DJI 4G Assistant v1.7.3

本次更新加强 Windows 本地服务的请求校验、错误处理和 AT 指令保护，不需要重新设置模块或重新下载 eSIM 套餐。

## 怎么下载和更新

1. 普通用户下载 **DJI-4G-Assistant-Setup-1.7.3-x64.exe**。
2. 退出正在运行的旧版 DJI 4G Assistant，再双击安装包完成更新。
3. 打开桌面上的 DJI 4G Assistant，插入模块，等待自动识别。

不想安装时，下载 **DJI-4G-Assistant-Portable-1.7.3-x64.exe** 直接运行。安装版和便携版功能相同，选一个即可，不需要另外安装 Node.js。

`SHA256SUMS.txt` 用于核对文件完整性；`Source code` 是开发者源码，不是软件安装包。程序尚无商业代码签名证书，Edge 或 Windows 可能提示“未常见下载”或“未知发布者”。请核对下载来源和校验值，不要关闭系统安全防护；如提示明确的恶意软件检测，应停止安装并核查。

## 修复和加强

- **异常请求处理：** 非法 JSON、空值、数组等不符合要求的请求返回明确错误，不再落入普通的内部异常流程。超出 20 KiB 的请求按实际字节数拦截，中文分块传输不会因为单个字符被拆开而损坏。
- **中断和启动失败：** 请求中途断开时及时结束处理；PowerShell 无法启动时返回操作失败，不再产生未处理的子进程错误。
- **隐私保护：** JSON 解析错误不回显原始内容；未预期的 API 异常只返回通用提示，诊断日志仅记录错误类别或代码，不直接输出原始异常堆栈。
- **AT 工具保护：** 默认只允许已列入清单的只读查询，拦截未授权写入和多指令拼接。未列入的指令可能显示“不允许”，这不代表模块故障。短信、电话和 eSIM 的常规操作仍使用各自的专用页面及确认流程。
- **串口队列回归：** 核对前一次操作失败仍会通知调用者，且不会阻塞后续串口或语音任务。
- **页面注入防护回归：** 对短信、eSIM 名称与标识、通知、通话记录中的恶意文本增加测试，确保作为文字显示，不作为网页脚本执行。

## 验证范围

- 99 项自动测试和 JavaScript 语法检查通过，包括真实 HTTP 请求边界测试。
- Chromium 中验证了 6 处动态渲染容器，测试文本没有生成可执行脚本或事件节点。
- 使用实际模块验证了自动串口识别、SIM 与蜂窝注册状态、短信读取、多 EID 套餐列表和通话状态查询。
- 核对了 Quectel ECM 网卡流量计数，不混入电脑 Wi-Fi 数据；该统计不是套餐剩余流量，也不是蜂窝互联网测速。
- 测试前后 USB 组成、USB 网络模式和 APN 查询结果一致。

本轮没有发送短信、拨打电话、切换或下载套餐、删除短信，也没有实测通话声音。因此这些操作不在本次实机验证结论内。只读读卡仍以标准入口和已适配的厂商入口为范围，不猜测未知私有入口。

本次发布的是 Windows 修复版，不新增 Android 或 iOS 直插管理能力。
