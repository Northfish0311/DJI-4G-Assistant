# 大疆 4G 助手 v1.7.11

## 普通用户下载哪个

下载 **DJI-4G-Assistant-Setup-1.7.11-x64.exe**。退出正在运行的旧版，双击安装，再从桌面打开“大疆 4G 助手”。无需卸载个人设置、安装 Node.js 或打开命令窗口。

- **Setup**：安装版，推荐使用，会创建快捷方式。
- **Portable**：免安装版，功能相同，下载后直接运行。
- **SHA256SUMS.txt**：安装包校验值。
- **Source code**：开发者源码，不是普通用户的安装包。

## 本次改进

### eSIM 套餐更容易查找

支持按名称、运营商、ICCID 搜索，并筛选全部、已启用或未启用套餐。不同 EID 分别记住筛选条件，结果数量始终对应当前空间。搜索和查看卡片空间不会启用或停用套餐。

刷新列表、切换语言或查看另一个 EID 时，展开的详情和未保存的昵称仍会保留；编辑中的光标位置也会恢复。草稿只存在当前页面内存，关闭页面或换卡后清除。点击“保存”并确认后才会写入卡片。

### 短信阅读不中断

阅读较早短信时，自动刷新保留同一条短信的阅读位置。新读到的记录通过“新短信”按钮提示，点击再跳到底部。位于底部时继续自动显示最新记录。刷新失败保留当前收件箱和回复草稿。

### 页面更清楚

统一套餐搜索框、状态筛选框和列表间距，减少重复的套餐标题，调整短信正文字号及行距，并适配窄屏浏览器。补充中英文控件名称和中文使用说明。

## 验证与边界

通过源码语法检查、干净源码回归测试，以及 1440、1024、390、320 像素宽度的模拟浏览器交互和截图检查。验证包含搜索、EID 状态隔离、未保存昵称与光标、短信阅读位置、新消息按钮和刷新失败恢复。

本次没有改动 USB、APN、IMS、套餐写入或电话声音实现，也没有新增真实运营商通话验证。电话声音仍是实验功能；套餐余额仍需运营商接口，不能用网卡流量代替。
