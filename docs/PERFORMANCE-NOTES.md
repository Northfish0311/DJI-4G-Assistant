# 1.8.1-preview.1 提速测试版

## 打开测试版

打开[测试版下载页](https://github.com/Northfish0311/DJI-4G-Assistant/releases/tag/v1.8.1-preview.1)，下载 `DJI-4G-Assistant-Portable-1.8.1-preview.1-x64.exe`。先退出正在运行的 DJI 4G Assistant，再双击下载的文件。这是免安装版本，不需要安装 Node.js，也不需要单独启动网页服务。不要与正式版同时运行。

本测试版沿用现有应用设置目录，不是隔离的沙盒；正常使用时，仍需确认写入操作。它没有自动修改 USB 模式、APN 或 eSIM 套餐。此次构建没有代码签名证书。

## 使用变化

- 启动只做基础连接、模块状态和 SIM 状态检查，不再等待完整 eSIM 套餐扫描和网卡详细查询。
- 第一次打开 eSIM、网络或短信页时，自动读取对应内容。同一次连接中再次切回来，不重复执行首次加载。
- 已识别串口时，手动刷新短信直接读取该端口，不再每次扫描全部串口。没有端口时仍自动查找；读取失败会显示失败，不会擅自换到另一个模块。
- 多个重叠的网卡完整刷新请求合并为一次查询。网卡变化或驱动变更后仍重新查询，不使用旧计数冒充新流量。
- 顶部“自动扫描”仍保留完整检查。首次进入 eSIM 页仍需等待真实读卡，优化没有减少 EID 探测范围或套餐数量。

## 验证

2026-10-23，本地自动测试 258 项通过，语法检查通过。

使用 Edge 无头浏览器运行真实页面脚本，全部 API 被模拟响应拦截，没有访问模块，没有发短信、拨号或修改套餐。

模拟延迟：基础读取 60 毫秒、网卡查询 300 毫秒、完整 eSIM 查询 1500 毫秒。三轮页面启动到可操作的中位数：

| 来源 | 中位耗时 | 首屏 API 请求数 |
| --- | --- | --- |
| 原始 1.8.0 | 6143 毫秒 | 7 |
| 本地优化版 | 3863 毫秒 | 5 |

这些数值包含本机浏览器和脚本加载开销，只用于此次受控对比，不代表真实模块或其他电脑的速度。首次直接进入 eSIM 页仍会等待套餐读取。

另外验证了短信刷新不重复找端口、两个模拟 EID 可展示、eSIM 直达链接、页面切换、1365 和 880 像素宽度的布局，没有发现浏览器脚本错误或横向溢出。

免安装包构建完成后，又直接读取包内页面进行同样的交互和截图检查。包内后端在自带 Electron 运行时中启动成功；认证、静态资源、USB 原生组件加载及 lpac 文件存在检查均通过，不依赖外部 Node.js 模块。这些检查不等于实机拨号或完整读卡测试。

## 边界

这次没有修改串口队列、通话逻辑、USB 模式、APN 或底层 eSIM 切换方式，也没有缩短硬件响应超时。真实硬件连接耗时、短信收发和通话声音尚未在这轮优化后复测。

本版标记为预发布测试版，不会自动升级已安装的 1.8.0，也不替换 GitHub 上的正式版下载入口。

如果 Windows 只识别出 USB 网卡、没有模块的 AT 串口，短信和 eSIM 管理暂时不可用。蓝牙 COM 口不是模块控制口。请先查看系统页的设备诊断；不要因为读卡失败而盲目改 USB 模式或切换套餐。
