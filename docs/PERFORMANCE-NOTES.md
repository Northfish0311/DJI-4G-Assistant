# 1.8.1 性能优化与验证

## 下载使用

打开[1.8.1 下载页](https://github.com/Northfish0311/DJI-4G-Assistant/releases/tag/v1.8.1)，普通用户下载 `DJI-4G-Assistant-Setup-1.8.1-x64.exe` 并安装；便携版为 `DJI-4G-Assistant-Portable-1.8.1-x64.exe`，可直接双击运行。先退出旧版，不需要安装 Node.js，也不需要单独启动网页服务。不要同时运行两个版本。

本版沿用现有应用设置目录，不是隔离的沙盒；正常使用时，仍需确认写入操作。它没有自动修改 USB 模式、APN 或 eSIM 套餐。此次构建没有代码签名证书。

## 使用变化

- 启动只读查询从 17 条 AT 指令减少到 10 条，SIM 状态和卡号指纹合并到同一次串口读取中；旧后端未返回 SIM 信息时仍单独读取。信号、运营商、注册、模块 IP、温度和 USB 模式仍保留。
- 短信未变化时跳过重复解析和列表布局计算，只更新读取时间、容量和操作状态。新短信、搜索、语言、草稿、本次已发送短信、删除权限或卡片变化时重新渲染，不会用旧列表冒充新内容。
- 启动只做基础连接、模块状态和 SIM 状态检查，不再等待完整 eSIM 套餐扫描和网卡详细查询。
- 第一次打开 eSIM、网络或短信页时，自动读取对应内容。同一次连接中再次切回来，不重复执行首次加载。
- 已识别串口时，手动刷新短信直接读取该端口，不再每次扫描全部串口。没有端口时仍自动查找；读取失败会显示失败，不会擅自换到另一个模块。
- 多个重叠的网卡完整刷新请求合并为一次查询。网卡变化或驱动变更后仍重新查询，不使用旧计数冒充新流量。
- 顶部“自动扫描”仍保留完整检查。首次进入 eSIM 页仍需等待真实读卡，优化没有减少 EID 探测范围或套餐数量。

## 验证

### 正式发布前实机验证

2026-10-26，在一台 Windows 电脑和一个已恢复正确串口驱动的模块上，使用与正式版相同的应用逻辑完成只读验证：自动发现 AT 口、SIM READY、LTE 注册、多 EID 与套餐列表查询均成功。驱动恢复是这台电脑上的单独维护操作，**不是助手安装包新增的一键修复功能**，不代表每台电脑都可以免装驱动。

三轮状态查询对比：

| 查询路径 | 三轮耗时（毫秒） | 中位数 |
| --- | --- | --- |
| 新启动查询 | 4965、4961、4963 | 4963 毫秒 |
| 原完整状态查询 + 单独 SIM 查询 | 8610、8610、8606 | 8610 毫秒 |

本机样本中的查询等待减少约 42%。这是 AT 状态查询的耗时，不是完整软件启动时间或蜂窝下载速度；模块、驱动和电脑不同，结果也会不同。验证没有发送短信、拨号或写入套餐，不公开卡号、EID、IMSI、号码或原始设备日志。

## 边界

这次没有修改串口队列、通话逻辑、USB 模式、APN 或底层 eSIM 切换方式，也没有缩短硬件响应超时。启动查询精简不影响手动完整扫描，也不减少 EID 探测范围。实机验证仅覆盖自动发现、状态和套餐列表读取；短信收发、套餐写入和通话声音尚未在这轮优化后复测。

本版以 1.8.1 正式发布，不会自动升级电脑上已安装的旧版。下载新版后退出旧版再运行或安装。

如果 Windows 只识别出 USB 网卡、没有模块的 AT 串口，短信和 eSIM 管理暂时不可用。蓝牙 COM 口不是模块控制口。请先查看系统页的设备诊断及 [Windows 驱动说明](Windows驱动说明.md)；不要因为读卡失败而盲目改 USB 模式或切换套餐。
