# DJI 4G Assistant v1.7.9

## 下载与安装

普通用户下载 **DJI-4G-Assistant-Setup-1.7.9-x64.exe**，退出旧软件后安装，再打开桌面图标。保留当前设置和已校验语音文件。Portable 是免安装版；Source code 不是安装包。

## 通话声音修复

- 声音路由启动时 USB 可能重新枚举：启动回包丢失后重新连接 ADB，核对原来的自有进程，不重复启动 helper。
- 声音路由确认后重新查找实际 USB 输入和输出，不沿用失效的声卡编号，也不把 Default / Communications 别名当成模块。
- 读取通话状态失败、超时或返回 ERROR 时不当成挂断，不关闭现有声音路由。确认结束后，排队清理前再核对一次，避免关闭新来的电话。
- 模块重启、拔插或 ADB 丢失后不显示旧的“语音已准备完成”。读取实际临时驱动和自有校准服务的状态。
- 声音停止导致 USB 短暂断开时重新连接完成清理；诊断与声音操作共用队列，不抢同一个 ADB 接口。
- 未连接、读取失败或型号不支持时禁用接口写入按钮；明确区分麦克风权限、声卡缺失和内部路由错误。

“打开 ADB 和声音”只开放接口，不代表网络已接受语音，也不代表双向声音已测试成功。一次性设置仍只支持精确匹配的 QDC507GLEFM21；不修改 APN、SIM/eSIM、ECM 或运营商 MBN，不强制打开不支持的固件接口。

## 验证范围

已通过状态失败保护、排队期间新来电保护、模块重启状态失效、ADB 启动回包丢失后的重连、声音停止重连、USB 声卡重新识别、耳机输出和麦克风释放的自动测试，以及桌面/手机宽度页面截图检查。

**修复后的稳定双向实机通话仍待验证。** 之前用户报告的“接通数秒、无声音后挂断”不能仅凭软件测试判定已解决；运营商、模块 DSP 和设备实际状态仍需核对。模块不在电脑上时，不会伪造实机通过结果。

设计核对参考固定版本的 [MaVo ModuleVoiceRuntime](https://github.com/moluncn/mavo/blob/0443dfdaf8aec086fd76ba2ee9152fd908114524/Sources/MaVo/ModuleVoiceRuntime.swift)，语音二进制仍使用原固定版本、固定大小和 SHA-256 校验，不包含未经校验的新驱动。

请只从本仓库下载，遇到 Edge / Windows 未签名提醒先核对来源和 SHA-256，不要关闭系统安全保护。
