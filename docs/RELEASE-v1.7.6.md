# Windows v1.7.6 中文更新说明

## 怎么更新

1. 退出旧版 DJI 4G Assistant。
2. 在本仓库 Releases 下载 `DJI-4G-Assistant-Setup-1.7.6-x64.exe`，双击安装。
3. 打开桌面上的 DJI 4G Assistant，模块保持原来的连接方式即可。

免安装用户下载 `DJI-4G-Assistant-Portable-1.7.6-x64.exe` 后双击运行；不用另开命令窗口或安装 Node.js。`Source code` 是开发者源码，不是安装包。

项目没有商业代码签名证书。Edge 或 Windows 首次运行可能提示安全风险；请核对本仓库下载地址及 `SHA256SUMS.txt`，详细步骤见 README。

## 修复页面排版

- “工作方式”里的 GitHub 页面、本地控制台、硬件范围说明，与标题使用相同的左右留白。
- “连接”里的 AT 端口、可选控制密码和四个按钮统一左右对齐。
- “端口、设备、查找 AT 口、模块”按钮与输入框保持 16 像素间距，左右及底部保留 22 像素留白，不再贴着边框。
- 窄窗口和手机浏览器使用两列按钮，较宽窗口使用四列；中英文切换不改变对齐规则。
- 网络页的网卡、本次下载、网关等九项数据统一左右留白，标签与数值对齐；电脑版使用白色底面，不再露出灰色网格底色。
- AT 工具作为完整工具区显示，标题、输入框与快捷按钮统一对齐，并与分隔线留出间距。

这四个按钮是四项检查操作，不代表连接了四个硬件模块。

## 验证与边界

运行 JavaScript 测试、语法检查及 1920、1440、1024、880、390 像素宽度的浏览器截图测试。检查概览、短信、eSIM、电话、网络、AT 工具、系统七个页面，以及展开后的工具区。新增系统页、网络数据、AT 输入区的留白和对齐检查，覆盖中英文与需要控制密码的布局；测试使用虚构数据，不包含个人短信或卡号。

本次仅修改 Windows 管理界面的排版，不改 VID/PID、USB 模式、APN、eSIM 或模块内部服务。v1.7.5 的功能和修复继续保留；本次没有重新验证短信送达或通话声音，不宣称对这些功能进行了新的修复。
