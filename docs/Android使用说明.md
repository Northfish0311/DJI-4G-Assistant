# 安卓远程管理版

当前为 0.1.0 开发测试版源码。尚未完成 APK 编译与真机验收，不表示已有可用安装包。

## 它做什么

大疆模块插在 Windows 电脑上，安卓手机或平板通过局域网管理电脑助手。**本版本不支持模块直接插安卓手机。** Windows 必须保持运行；电话控制不等于把通话音频传到手机。

第一版提供扫码/手动配对、加密保存配对信息、加载管理网页、网页操作确认/输入弹窗、手动重连和忘记电脑。扫码使用设备相机，不依赖 Google Play 服务；拒绝相机权限后可手动输入。

## 安装和使用（构建通过后）

1. GitHub Actions 的 `Build Android remote companion` 必须显示成功。从该次运行的 Artifacts 下载 `DJI-4G-Remote-Android-test`，解压找到 APK，校验同目录 SHA256。
2. 将 APK 传到安卓手机，打开安装。系统如要求，只给本次使用的浏览器或文件管理器允许“安装未知应用”，装完可关闭该权限；不要求关闭系统安全扫描。
3. 打开 Windows 助手，模块留在电脑上。两台设备连接同一可信局域网。
4. 安卓 App 点击“扫描配对码”，扫描 Windows 顶部“连接 iPhone / iPad”里的二维码（当前共用此入口，标题尚未改成安卓）。也可填写电脑的局域网地址和配对密码。
5. 断线后确认电脑仍运行，再点“重连”。密码失效时选择“断开 → 忘记”，然后重新扫码。

当前最低 Android 7.0（API 24），需要可用且及时更新的 Android System WebView。不是所有老设备和定制系统都已经验证。建议在受安全更新支持的系统上测试。

## 安全与限制

- 这是调试签名测试 APK，不是商店正式版。每次云端构建的调试证书可能不同，安装更新可能需要卸载旧测试版并重新配对。正式发布前必须配置长期签名密钥。
- 不需要 Apple 开发者账号或 TestFlight；安卓仍必须有 APK 签名，调试版由构建工具生成。
- 配对密码使用 Android Keystore 支持的 AES-GCM 加密保存，应用备份已关闭。不要求联系人、短信、电话、存储或 USB 权限。
- 手机不读取自己的短信；页面展示的是 Windows 模块中的信息。
- 仅接受 RFC1918 私有 IPv4、链路本地 IPv4 或 `.local` 地址。不要输入手机的 `127.0.0.1`；不支持公网配对和当前版本的 IPv6 配对。
- HTTP 局域网连接不是加密传输。只在可信网络使用，禁止开放公网端口。网页不能跳转或加载到其他来源，也不提供原生 JavaScript 桥。
- 不自动重试发短信、切套餐等写操作。网页提示的高风险确认不会跳过。
- 云端截图只验证配对页布局，不代表真实扫码、模块操作或手机兼容性通过。

## 开发构建

使用 JDK 17、Gradle 8.11.1、Android SDK 35，在 `android/` 执行：

```text
gradle testDebugUnitTest lintDebug assembleDebug
```

首次需要联网下载固定版本依赖；本项目未提交 Gradle wrapper 二进制，需自行安装对应版本或使用仓库工作流。二维码组件为 JourneyApps ZXing Android Embedded 4.3.0（Apache-2.0），见第三方说明。
