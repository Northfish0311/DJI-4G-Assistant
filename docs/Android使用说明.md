# 安卓远程管理版

当前为 **0.2.0 远程测试版**。[直接下载 APK](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/android-remote-v0.2.0/DJI-4G-Remote-Android-0.2.0-test.apk)或打开[发布页](https://github.com/Northfish0311/DJI-4G-Assistant/releases/tag/android-remote-v0.2.0)。已经通过云端编译、单元测试、静态检查和模拟器测试；真实手机扫码、连接 Windows 和模块操作仍需测试，不是正式稳定版。

## 它做什么

大疆模块插在 Windows 电脑上，安卓手机或平板通过局域网管理电脑助手。**本版本不支持模块直接插安卓手机。** Windows 必须保持运行；电话控制不等于把通话音频传到手机。

第一版提供扫码/手动配对、加密保存配对信息、加载管理网页、网页操作确认/输入弹窗、手动重连和忘记电脑。扫码使用设备相机，不依赖 Google Play 服务；拒绝相机权限后可手动输入。

配对页由安卓 App 提供，**配对成功后的管理页面由 Windows 助手提供**。因此，只升级手机 APK 不一定会改变管理页面；需要电脑端也包含相应的界面更新。

### 管理页面调整（随 Windows 1.7.4 提供）

先退出电脑端旧版，再安装 [Windows 最新版](https://github.com/Northfish0311/DJI-4G-Assistant/releases/latest)。打开助手后，在安卓 0.2.0 App 里重新连接电脑即可加载新版页面，无需重新安装 APK。重新连接会重新加载网页，请先处理未发送的草稿；此操作不会发送短信或切换套餐。

- 手机底部提供“概览、eSIM、短信、电话、更多”；网络、AT 工具、系统和语言切换位于“更多”。平板使用左侧导航。
- 概览优先显示运营商、制式、SIM 和信号。USB、串口、网络详情及温度可展开“设备详情”查看。
- eSIM 按实际返回的 EID 显示卡片空间，数量不是固定两张。点击空间只查看其套餐，不会自动启用、停用或切换底层芯片。
- 正在使用的套餐突出显示状态；需要停用时，展开该套餐的“更多操作与卡号”。套餐切换仍会确认目标 EID 和套餐，不跳过确认。
- 短信页先显示会话列表。点击号码查看正文，点击左上角返回；阅读短信不会自动弹出键盘。不同会话和新短信各自保留当前页面内的草稿，返回列表、刷新短信或取消发送确认不会清空；换卡、退出或重新加载页面后不保留。平板可同时显示列表与正文。
- 电话页优先显示通话状态和拨号盘，来电时显示接听、挂断。手机端明确标注声音由 Windows 处理，不显示只能在电脑本机使用的音频设备按钮。
- 网络页优先显示上传、下载速度和本次流量；IP、网关及驱动放在“连接详情”。这些是 Windows USB 网卡统计，不是套餐剩余流量。

上述布局使用示例数据检查手机、平板、中英文及原有桌面页面，不调用真实模块、不发送短信、不切换套餐。浏览器截图不是安卓真机软键盘或通话测试。不代表增加了新的卡片兼容性，也不代表真实手机读卡验证。仅支持标准入口和已适配厂商入口，未知私有入口不猜、不自动切换，读不到会明确提示。

## 0.2.0 更新了什么

请安装本页链接中的 **0.2.0** APK，旧 0.1.0 安装包不会自动获得这些改进：

- **多台电脑：** 新电脑不会覆盖旧记录；在“更多操作”里选择“更换电脑”，可回到配对页选择已保存的电脑或添加新电脑。“忘记这台电脑”只删除选中的配对。
- **局域网搜索：** 点击“搜索局域网电脑”，等待约 6 秒。选择电脑后仍需输入它提供的配对密码；搜索到电脑不等于获得授权。未发现时可直接扫码；目前不提供 IPv6 地址配对。
- **配对损坏恢复：** 读取失败会明确提示，点击“重置本机配对”并确认后重新扫码。只删除手机保存的地址、密码和加密密钥，不修改 Windows 或模块。清除失败会提示，不会假装已删除。
- **保留输入：** 切到其他 App 再回来，只要系统没有回收 App，就不会自动刷新正常页面。主动重载或更换电脑前仍会确认。未发送短信、激活码等草稿只在当前页面中临时保留；退出 App 或被系统回收后，未保存的输入可能丢失。
- **有限重连：** 仅管理网页加载失败时，按 1、2、4 秒等待后尝试重新加载，最多三次。密码失效等授权错误不会自动重试。不会重新发送短信、下载或切换套餐等写操作。

## 安装和使用

1. [直接下载 0.2.0 APK](https://github.com/Northfish0311/DJI-4G-Assistant/releases/download/android-remote-v0.2.0/DJI-4G-Remote-Android-0.2.0-test.apk)。也可打开[安卓测试版发布页](https://github.com/Northfish0311/DJI-4G-Assistant/releases/tag/android-remote-v0.2.0)，展开 Assets，选择 `DJI-4G-Remote-Android-0.2.0-test.apk`，不要下载 Source code。
2. 将 APK 传到安卓手机，打开安装。系统如要求，只给本次使用的浏览器或文件管理器允许“安装未知应用”，装完可关闭该权限；不要求关闭系统安全扫描。
3. 打开 Windows 助手，模块留在电脑上。两台设备连接同一可信局域网。
4. 安卓 App 点击“扫描配对码”，扫描 Windows 顶部“连接手机 / 平板”里的二维码。也可填写电脑的局域网地址和配对密码。
5. 管理网页加载失败时，App 会尝试重连；仍然失败时，检查电脑和网络，再点击右上角的重新连接图标。正常显示的页面不会因返回 App 而强制刷新。密码失效时，点击右上角“更多操作”，选择“忘记这台电脑”，确认后重新扫码。忘记电脑只清除手机里的配对信息，不会删除 eSIM 套餐，也不会修改模块设置。

当前最低 Android 7.0（API 24），需要可用且及时更新的 Android System WebView。不是所有老设备和定制系统都已经验证。建议在受安全更新支持的系统上测试。

## 常见问题

- **显示“禁止安装未知应用”：** 在系统提示中只授权本次下载来源，不用开启 USB 调试或 root，不要关闭安全扫描。企业管理设备可能禁止侧载，遵循设备管理政策。
- **显示“应用未安装/签名冲突”：** 若装过另一构建的测试版，可能签名不同。确认新包来自本仓库后，可以卸载旧测试版再装；手机配对信息会清除，需要重新扫码，不会因此删除模块内的 eSIM 套餐。
- **扫码后连接失败：** 检查电脑助手仍运行、手机和电脑同一局域网、Wi-Fi 没有客户端隔离，以及 Windows 防火墙允许该应用在专用网络访问。不要为排错关闭整个防火墙。
- **网页空白：** 更新 Android System WebView 或 Chrome，返回 App 点“重连”。不要反复提交短信或切套餐操作。
- **按钮提示权限未开放：** 功能权限由 Windows 服务决定。安卓 App 不绕过服务的授权与高风险确认。
- **手机直插模块后 App 找不到：** 当前是远程管理版，必须由 Windows 连接模块。

## 安全与限制

- 这是调试签名测试 APK，不是商店正式版。每次云端构建的调试证书可能不同，安装更新可能需要卸载旧测试版并重新配对。正式发布前必须配置长期签名密钥。
- 不需要 Apple 开发者账号或 TestFlight；安卓仍必须有 APK 签名，调试版由构建工具生成。
- 配对密码使用 Android Keystore 支持的 AES-GCM 加密保存，应用备份已关闭。不要求联系人、短信、电话、存储或 USB 权限。
- 手机不读取自己的短信；页面展示的是 Windows 模块中的信息。
- 仅接受 RFC1918 私有 IPv4、链路本地 IPv4 或 `.local` 地址。不要输入手机的 `127.0.0.1`；不支持公网配对和当前版本的 IPv6 配对。
- HTTP 局域网连接不是加密传输。只在可信网络使用，禁止开放公网端口。网页不能跳转或加载到其他来源，也不提供原生 JavaScript 桥。
- 不自动重试发短信、切套餐等写操作。网页提示的高风险确认不会跳过。
- 云端截图只验证配对页布局，不代表真实扫码、模块操作或手机兼容性通过。

## 开发构建

源码中的自动化流程已加入手动连接展开/收起、空地址校验和大字体截图检查。是否通过要看对应提交的 Actions 结果；不要把已添加测试当成真机验证完成。截图不覆盖真实扫码、电话音频和模块操作。

使用 JDK 17、Gradle 8.11.1、Android SDK 35，在 `android/` 执行：

```text
gradle testDebugUnitTest lintDebug assembleDebug
```

连接测试用安卓设备或模拟器后，可以另外执行：

```text
gradle connectedDebugAndroidTest
```

这组测试会安装测试 App、清空它在测试设备上的本地配对并使用虚构电脑地址，测试结束后构建工具可能卸载 App。请使用专门的测试设备或模拟器，不要在保留重要配对记录的日用手机上直接运行。测试不会向真实模块发送短信、拨打电话或修改 eSIM。

首次需要联网下载固定版本依赖；本项目未提交 Gradle wrapper 二进制，需自行安装对应版本或使用仓库工作流。二维码组件为 JourneyApps ZXing Android Embedded 4.3.0（Apache-2.0），见第三方说明。
