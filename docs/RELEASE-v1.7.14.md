# 大疆 4G 助手 v1.7.14

## 下载与安装

普通用户只需下载 `DJI-4G-Assistant-Setup-1.7.14-x64.exe`，先退出旧版，再双击安装。
`Portable` 是免安装版，`SHA256SUMS.txt` 用于核对文件完整性，`Source code` 是开发源码，均不需要一起下载。

软件尚未购买商业代码签名，Edge 或 Windows 可能显示发布者/信誉提醒。请核对来源为本仓库，不要关闭系统安全防护。

## 这次改了什么

- **实时流量更轻快：** 首次读取完整网卡资料后，后台优先快速采样字节计数，不重复扫描全部驱动。插拔、地址变化、每分钟检查和手动刷新会重新读取完整资料；快速采样不可用时兼容回退。
- **连接地址更准确：** 仅本机监听不再显示局域网配对地址；不将模块常见的 USB 网卡地址或常见虚拟网卡地址自动推荐为手机入口。程序自动选择端口时，输出实际端口。
- **配对失败可直接重试：** 中文提示说明“仅本机”或“没有共享局域网”，隐藏空二维码和无效地址，新增刷新图标；失败时不会保留旧配对链接或绿色就绪标记。
- **布局检查：** 配对与网络页检查桌面、平板及窄屏宽度，继续保留套餐草稿和短信阅读位置。

手机远程管理仍需要 Windows 保持运行，并接入同一可信局域网。生成配对码不等于已验证防火墙或路由器允许连接。没有新增模块直插手机管理能力。

## 测试与边界

本轮对已连接模块进行了只读检查：串口、网络注册、多 EID 套餐列表、短信和 USB 网卡计数器正常返回。快速采样在该测试环境中约 1.3～1.5 秒，其他电脑和驱动可能不同；首次完整查询仍可能较慢。

自动测试覆盖刷新并发、换网卡、失败回退、元数据过期、地址筛选和本机监听限制；页面在 1440、1024、390、320 像素宽度下完成截图检查。

未改 USB 模式、未切换套餐、未发送短信或进行真实通话。通话声音仍属实验功能，本次不宣称修复所有运营商的语音兼容问题。流量统计不是套餐剩余流量。
