# 大疆 4G 助手 1.8.1-preview.2：继续提速

## 怎么用

1. 下载 `DJI-4G-Assistant-Portable-1.8.1-preview.2-x64.exe`。
2. 退出正在运行的旧版，再双击下载的文件。
3. 插上模块，等待识别；打开短信、eSIM 或网络页时自动读取对应内容。

这是免安装测试版，不需要 Node.js、启动脚本或另开浏览器。若使用 `Setup` 文件，则按提示安装。`SHA256SUMS.txt` 用于校验，`Source code` 是开发源码，普通用户不用下载。本版不替换正式版入口，不会自动升级已经安装的软件。

软件没有商业代码签名，Edge 或 Windows 可能显示安全提醒。请确认文件来自本仓库，并核对 SHA256；不要关闭系统安全防护。

## 比上一轮更快在哪里

- 启动 AT 查询从 17 条减少到 10 条，SIM 状态合并到同一次串口读取中；旧后端不支持时仍兼容单独读取。
- 短信内容没有变化时跳过重复解析和布局计算，只更新读取时间、容量和操作状态。
- 新短信、搜索、草稿、语言、权限和卡片变化仍重新渲染，保留当前会话和阅读位置。
- 完整自动扫描、eSIM 多 EID 探测范围以及硬件响应超时保持不变。
- 继续保留按需读取 eSIM/网络信息、短信刷新复用已识别 AT 口、重叠网卡刷新合并等优化。

## 测试结果与边界

270 项自动测试、语法检查和包内启动检查通过。已检查桌面、紧凑窗口及手机宽度的页面截图、搜索、新短信、草稿和两个模拟 EID 的展示。

本机浏览器基准使用 500 条模拟短信、20 个会话：连续 20 次内容不变的刷新，5 轮耗时中位数由 preview.1 的 101.4 毫秒降到本版的 10.6 毫秒。**这是页面计算开销，不含真实串口读取，不能理解为上网或整机启动速度提高相同比例。**

本轮真实读卡、短信收发和通话尚未复测。电话声音仍是实验功能；本版没有修改驱动、USB 模式、APN、通话逻辑或卡内套餐。测试版与正式版共用应用设置目录，不要同时运行。

如果 Windows 只有 USB 网卡，没有可用的模块 AT 串口，短信和 eSIM 管理仍不能读取。请先检查设备驱动；不要把蓝牙 COM 口当成模块端口，也不要盲目修改模块设置。

详细方法见[性能优化记录](https://github.com/Northfish0311/DJI-4G-Assistant/blob/main/docs/PERFORMANCE-NOTES.md)。
