# iPhone / iPad 远程管理 v1.0.2

配合 **Windows 1.7.4** 使用的实验性远程客户端，最低 iOS/iPadOS 16。模块仍插在 Windows 电脑上，电脑保持运行。**不是模块直插手机的独立版，不是 App Store 正式版，TestFlight 尚无公开邀请。**

## 如何更新

1. 先在电脑安装 Windows 1.7.4。
2. 已安装旧 iOS 远程客户端的用户，重新连接电脑即可看到新的短信、eSIM、电话和网络页面。
3. 如需本次客户端的重载确认和连接错误修复，下载新的 **Unsigned.ipa**，经有效 Apple 签名后安装。未签名 IPA 不能直接点开安装。

只想直接使用而不处理签名，可以用 Safari 打开 Windows 助手显示的局域网地址。不是手机自己的 `127.0.0.1`。

## 更新内容

- 配合电脑端新页面，iPhone 使用底部五项导航，iPad 使用左侧导航，适配中英文及短信列表/正文切换。
- 手动重载正常页面前先确认，避免误触清空未发送短信和未保存的输入；取消则保留当前页面。
- 主页面的 HTTP 错误不再当作已连接；401/403 授权错误停止自动重试。临时故障最多自动重试三次，切回前台不重置重试预算。
- 网页销毁时解除旧回调，避免旧连接影响新页面。不会自动重复发送短信、拨号或切换套餐。
- 补充中英文提示、连接恢复策略单元测试及中文安装说明。

发布流程要求模拟器构建、配对和恢复策略单元测试、iPhone/iPad 配对页截图及未签名真机架构编译成功。这不是实际手机扫码、软键盘、断网恢复、短信/eSIM 写操作或通话声音已经验证的结论。通话声音仍由 Windows 处理。

密码保存于 Keychain；只在可信局域网使用。HTTP 局域网连接不是加密通道，不开放公网端口。读卡仅支持标准和已适配厂商入口，不猜测未知私有入口。
