# DJI 4G Assistant v1.7.4

本次更新优化手机和平板远程 App 的管理页面。页面由 Windows 助手提供，因此需要更新电脑端；已有安卓 0.2.0 无需重复安装。Windows 桌面仍保留原有导航和操作布局。

## 怎么下载和更新

1. 普通用户下载 **DJI-4G-Assistant-Setup-1.7.4-x64.exe**。
2. 先退出电脑上正在运行的旧版 DJI 4G Assistant，再双击安装包更新。
3. 打开桌面的 DJI 4G Assistant，模块仍插在 Windows 电脑上。
4. 在安卓 0.2.0 App 中重新连接电脑，即可加载新版页面。重新连接会重新加载网页，请先处理未发送的草稿。

无需重新设置 USB 模式、重新下载 eSIM 套餐或重新安装 Node.js。不想安装时，可选 **DJI-4G-Assistant-Portable-1.7.4-x64.exe**，安装版和便携版选一个即可。

`SHA256SUMS.txt` 用于校验完整性；`Source code` 是开发者源码，不是软件安装包。项目尚无商业代码签名证书，Edge 或 Windows 可能提示下载不常见或未知发布者。请核对本仓库来源和校验值，不要关闭系统防护；明确的恶意软件检测应停止并核查。

## 页面改进

- **导航：** 手机使用概览、eSIM、短信、电话、更多五个入口；网络、AT 工具、系统及语言切换放在更多中。平板保留左侧导航。
- **概览：** 优先显示运营商、网络制式、SIM 和信号；USB、串口、温度等放在可展开的设备详情。
- **eSIM：** 按实际返回的 EID 显示空间，当前空间和使用中的套餐更清晰。点击空间仅切换查看内容，不会自动切套餐；停用入口收进更多操作，写入确认仍保留。
- **短信：** 手机先显示会话列表，点击号码查看正文，左上角可返回。阅读不会自动弹出键盘；每个会话与新短信分别保留当前页面中的草稿，取消发送确认不会清空。平板支持列表与正文并排显示。
- **电话：** 优先显示状态和拨号盘；来电及通话期间突出接听、挂断等当前操作。手机端明确提示声音由 Windows 处理，不显示电脑本机音频按钮。
- **网络：** 实时上传、下载速度和本次流量集中显示，IP、网关、驱动收进连接详情。统计仅针对 Windows USB 网卡，不是套餐剩余流量。
- **显示：** 统一字体、间距、图标和触摸按钮，并适配中英文、小屏与平板。

## 验证与限制

- 完整 113 项自动测试和 JavaScript 语法检查通过，包含 28 项前端相关检查；覆盖 EID 查看不写入、短信草稿返回、换卡清空、桌面入口保留，以及桌面和手机两种页面的文本注入防护。
- 使用示例数据完成 320、390、412、768、1024、1440 像素宽度的浏览器截图检查，覆盖中英文、安卓/iOS 远程页面及原有桌面布局。
- 检查了两张、三张及空 EID 列表，短信会话切换、取消发送确认、来电显示与网络布局；界面检查未向模块发出写请求。
- 本次没有重新实测真实手机扫码、软键盘、短信送达、eSIM 写入或通话声音，截图不能代替真机验证。iOS 仍是实验性远程客户端，TestFlight 尚未开放；不新增安卓或 iPhone/iPad USB 直插能力。
- 草稿只保留在当前页面内，换卡、重载或退出后不保留。读卡仍仅支持标准入口和已适配厂商入口，未知私有入口不猜、不自动切底层芯片。
