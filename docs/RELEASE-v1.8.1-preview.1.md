# 大疆 4G 助手 1.8.1-preview.1：提速测试版

## 怎么用

1. 下载 `DJI-4G-Assistant-Portable-1.8.1-preview.1-x64.exe`。
2. 退出正在运行的旧版，再双击下载的文件。
3. 插上模块，等待识别；打开短信、eSIM 或网络页时自动读取相应内容。

这是免安装测试版，不需要 Node.js，不需要启动脚本，也不需要另开浏览器。`SHA256SUMS.txt` 用于校验，`Source code` 是开发源码，普通用户不用下载。正式版仍保留，不会自动更新为本测试版。

软件没有商业代码签名，Edge 或 Windows 可能提示未知发布者或信誉不足。请核对来源为本仓库和文件 SHA256，不要关闭系统安全防护。

## 这次改了什么

- 启动先完成基础连接和 SIM 状态检查，不再等待完整 eSIM 扫描与网卡详细查询。
- 第一次打开短信、eSIM 或网络页时再加载对应内容；完整自动扫描入口仍保留。
- 已识别 AT 串口时，短信刷新直接读取，不重复扫描全部串口；没有端口仍自动查找，读取失败不会擅自切到其他模块。
- 多个重叠的网卡刷新合并为一次；失效后的数据仍重新读取，不拿旧计数冒充实时流量。
- 加强安装包检查，验证包内 USB 原生组件和依赖能够独立加载。

## 验证与限制

258 项自动化测试和语法检查通过；已完成包内服务启动、鉴权、静态资源、USB 组件、lpac 文件以及页面切换和截图检查。

浏览器检查使用模拟模块响应，两个 EID 的展示验证也是模拟数据。真实短信收发、eSIM 读取和通话尚未在本轮完成复测，因此本版标记为测试版。电话声音仍属实验功能。

没有修改串口队列、通话逻辑、USB 模式、APN 或底层 eSIM 切换方式，没有缩短硬件响应超时。打开程序不会自动改卡内套餐。测试版与正式版沿用同一应用设置目录，不要同时运行。

如果只有 USB 网卡而没有可用的模块 AT 串口，暂时无法读取短信或管理 eSIM。先查看设备诊断，不要盲目切换 USB 模式。详细说明见 [性能优化记录](https://github.com/Northfish0311/DJI-4G-Assistant/blob/main/docs/PERFORMANCE-NOTES.md)。
