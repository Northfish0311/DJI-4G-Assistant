# DJI 4G Assistant v1.7.7

## 下载哪个

- **Setup-1.7.7-x64.exe**：安装版，推荐普通用户。安装后打开桌面上的 DJI 4G Assistant。
- **Portable-1.7.7-x64.exe**：免安装版，双击运行。
- **SHA256SUMS.txt**：用于核对下载文件。Source code 是开发源码，不是安装包。

## 本次修复

- 下载语音文件显示即时状态、文件名和进度；超时、GitHub 连接失败、校验失败、磁盘写入失败分别提示。自动重试连接，保留已校验文件。
- 修复 Windows 模块麦克风和扬声器同名为 AC Interface 时被误判为无声卡的问题；按输入、输出端点识别，不再要求 AS Interface 名称。
- 修复临时语音驱动准备时，内部脚本的 exit 导致程序无法读取执行结果的问题。
- 电话设置增加 IMS/VoLTE 检查和“启用 VoLTE”。仅支持已验证的 QDC507GLEFM21，修改前保存该模块备份，读回一致才重启。可恢复对应模块的 IMS 备份；不修改 APN、USB 网络模式、eSIM 或运营商 MBN。
- 拨号被拒绝时自动只读查询原因，区分 IMS 已关闭、LTE 未注册、VoLTE 未启用和 IMS 承载未激活。
- 普通实体 SIM 没有 EID 时不再被当作网络故障。eSIM 卡未知管理入口仍明确显示暂不支持，不尝试私有切换指令。

## 第一次使用电话

1. 插入支持通话的 SIM，打开软件进入“电话”。
2. 展开“通话设置”，点击“刷新状态”。若显示 IMS 已关闭，点击“启用 VoLTE”并确认，等模块重新连接。
3. 下载语音文件，按页面状态开启模块声音接口。首次改变 USB 配置会备份并重启。
4. 通话接通后，选择电脑麦克风和扬声器，点击“启动声音”。

**能上网不等于通话一定可用，显示 VoLTE 配置已启用也不等于运营商已接受语音。**
本次中国电信实体 SIM 实机测试：ECM 上网通过；IMS 已启用、IMS 承载已激活；模块麦克风和扬声器出现；匹配临时语音驱动准备成功。用户呼叫已从立即拒绝进展到可呼叫后中断，模块报告 `CEER: 0,25`，稳定通话与双向声音仍未验证。不要把这个版本理解为所有运营商和套餐的通话保证。

Edge 或 Windows 可能因软件未购买商业代码签名而提示未知发布者。只从本仓库 Releases 下载，核对文件名和 SHA-256，不要关闭系统安全防护。
