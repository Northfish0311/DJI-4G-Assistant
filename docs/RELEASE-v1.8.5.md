# 大疆 4G 助手 1.8.5

## 怎么升级

1. 下载 **DJI-4G-Assistant-Setup-1.8.5-x64.exe**。
2. 退出旧版，再双击安装包完成安装。
3. 插好卡和模块，打开 DJI 4G Assistant，等待自动识别。

不需要安装 Node.js 或运行脚本。免安装版 `Portable-1.8.5-x64.exe` 功能相同，两个版本不要同时运行。`Source code` 是开发源码，不是安装包；`SHA256SUMS.txt` 用于校验文件。

软件尚无商业代码签名证书，Edge 或 Windows 可能显示安全提醒。请确认文件来自本仓库 Releases 并核对校验值，不要关闭系统安全防护。

## eSIM 列表更可靠

- **换卡后先检查当前卡。** 每次复用列表前，会重新只读查询 SIM 状态和卡标识，不再仅凭 COM 口相同就使用旧列表。
- **扫描结果再次核对。** 完整扫描前后的卡标识不一致时，旧结果不会显示、缓存或写回本地记录。扫描期间更改套餐、备注或管理入口时，也会使旧结果失效。
- **未启用套餐的 eUICC 仍可读取。** 如果读不到活动卡标识，会执行实际扫描而不复用缓存，不会因此直接禁止 eSIM 管理。
- **手动刷新会重新扫描。** 点击 eSIM 页的刷新按钮会跳过列表缓存；普通重复读取在核对当前卡后可复用短时缓存。重叠读取会共用一次扫描。
- **写入后不沿用旧列表。** 启用、停用、删除、下载、套餐改名和通知处理共用缓存失效逻辑；即使写入报错或结果不确定，也会在下次读取时重新核对。
- **读取不完整可以重试。** 部分套餐读取失败或空结果不会作为完整列表缓存，旧任务也不能覆盖新扫描或清掉新任务的等待状态。

eSIM 写入前仍会单独检查目标 EID 和通话状态，列表缓存不能绕过这些保护。

## 实测与限制

305 项自动测试通过，包括模拟换卡、扫描中移除卡、失效结果迟到、并发读取、手动刷新和写入失败后的缓存处理。

本轮完成真实模块的只读检查：自动发现 AT 口、SIM 就绪状态、多 EID 套餐列表、缓存复用和手动刷新；各次读取结果一致。单一测试环境下首次扫描约 1.56 秒，核对当前卡后复用列表约 73 毫秒，强制刷新约 1.31 秒。这些是接口查询耗时，不是完整启动时间或其他电脑的速度保证。

本轮没有发送短信、拨号、切换套餐、下载套餐或更改 USB 配置。物理换卡时序由模拟测试覆盖，未进行真实拔卡对比；通话声音仍属实验功能。读取结果不确定时先刷新核对，不要直接重复写入。

仅支持标准管理入口和已适配的厂商入口。未知私有入口不猜、不自动切换底层芯片，读不到时明确提示暂不支持。无法识别 AT 口时，请先看 [Windows 驱动说明](Windows驱动说明.md)，不要盲目改 APN 或 USB 模式。
